## 1. 背景与两套系统的关系

### 1.1 选股包是什么

`价格行为学_分享包_20261004.zip`（124 文件，2026-10-04 打包，`sanitized_export`）是
A 股盘后五模型交易计划系统的对外脱敏版。经实际代码核验（96 个 .py 的 import 闭环、
入口链、requirements、惰性依赖），它是**完整可独立运行的选股系统**：

- 五模型并行：①涨停1号(V2) ②Sector板块下钻 ③量比模型 ④情绪观察模型 ⑤涨停策略2号
- 盘前建三池（涨停/情绪风向标/涨停2号）→ 风险层剔除退市/ST → 五模型计算 → 统一交易计划
- 共同裁决门：`EV = WR×RR_T1 − (1−WR) > 0.05R`
- 免账号化：长桥替身（腾讯行情）、多数据源自动切换、一键安装/运行脚本
- 已知边界：WR 为启发式先验（`SOURCE_ADAPTED_HEURISTIC / NOT_CALIBRATED`），
  未经独立校准；只产出交易计划，不自动交易

### 1.2 本仓库（Focus v1）是什么

Al Brooks 价格行为的严格重构：A股 30m 单一框架、双核四结构+区间开关
（H2/L2/breakout/wedge/final_flag/tr_fade）、三层可审计架构
（bar-counting → qualification → actionability）、单一事实源 `src/focus_config.py`。
诚实现状：随机 5 股 walk-forward 回测 34 笔，超额 **-0.87%**，诊断结论为
**regime 错配**（趋势信号在震荡环境反复止损）——证据链完整保留，含负面结果。

### 1.3 为什么组合

两套系统失败模式互补：

| 系统 | 强项 | 已证失败模式 |
|---|---|---|
| 选股包 | 候选覆盖广、数据链工程成熟 | WR 未校准 → EV 门放进假信号 |
| Focus v1 | 结构严格可审计、有 regime 开关 | 单独选股覆盖窄、无超额收益 |

**组合假设（未验证，是本计划的中心命题）**：

> 选股包负责"从哪找票"，Focus v1 负责"这票现在能不能做"——
> 用 30m 结构门 + regime 门砍掉未校准 EV 门放进来的假信号。

## 2. 总体架构（四层单向流）

```
L1 选股层（选股包，只读黑盒）
    15:05 后运行 → outputs/sync/统一交易计划_*.md（今日可买/盯盘/K1观察三档）
        ↓ 唯一接口
L2 解析层（新建 bridge 模块，~200 行）
    md → candidates_YYYYMMDD.json（票/来源/S/T1/WR/EV/STOP/分层档位）
        ↓
L3 分析裁决层（本仓库 Focus v1，双门裁决）
    每候选取 30m K线 → ①regime 判定（区间开关门控）
                      ②双核四结构扫描
                      ③actionability 核验（入场/止损/目标可执行性）
        ↓ 四象限
L4 验证层（paper ledger 双轨）
    A 轨 = 仅选股包门（基线）；B 轨 = 双门（组合）
    逐笔记录 → 周度统计 → stop gate 判定
```

工程铁律：
- 单向数据流；L1 只读，绝不反写选股包目录
- 选股包 = 2026-10-04 冻结快照，当稳定选股器用，不与其母生产系统同步
- 本仓库 public，选股包代码/数据**永不入库**（§6）

## 3. 双门裁决四象限（L3 核心规则）

| 选股包 EV 门 | Focus v1 结构门 | 裁决 | 理由 |
|---|---|---|---|
| ✓ | ✓ | 执行候选 | 双独立证据，最高置信 |
| ✓ | ✗ | 降级观察 | EV 未校准、结构不认 → 不做但记录（检验 Focus 门价值的关键样本） |
| ✓ | ○ regime 不明 | 盯盘待定 | 震荡/趋势不明不做新仓，出触发条件 |
| K1观察档 | ✓ | 反向研究池 | 只入 ledger 不执行 |

验证抓手：A 轨亏损单若集中在 regime=区间日 → 直接证明 B 轨有价值；
若不集中 → 假设不成立，及时止损方向。

## 4. 验证闭环（预注册，防事后找补）

双轨 ledger 从第一天分开记（复用 STRICT_PAPER_LEDGER 模式）：

| 指标 | A 轨 | B 轨 | 判读 |
|---|---|---|---|
| 胜率 | ✓ | ✓ | B > A 才成立 |
| 盈亏比 | ✓ | ✓ | 砍假信号的直接体现 |
| 触发率 | — | ✓ | B 的代价：过滤过紧则暴跌 |
| 踏空率 | — | ✓ | 被 Focus 门砍掉但后来上涨的票 |
| 样本量门槛 | — | — | ≥30 笔/轨才下结论 |

**Stop gate（预注册）**：运行 8 周或 60 笔后，若
① B 轨胜率提升 < 5 个百分点，或 ② 踏空率 > 40%，
判定过滤层无净增益 → 放弃双门或重新设计 regime 门。

## 5. 分阶段建设与计划清单

| 阶段 | 内容 | 出口判据（不过不进下一阶段） | 状态 |
|---|---|---|---|
| P0 接口验证（1天） | 选股包真跑一天 → 手工核对解析输出与 md 一致 | 三档票数/EV/止损逐字段对得上 | 待启动 |
| P1 桥接+基线（2-3天） | 解析器 + A 轨 ledger 开录 | 连续 3 交易日无人工干预跑通 | 未开始 |
| P2 双门裁决（3-5天） | Focus v1 候选分析管线 + 四象限输出 + B 轨 ledger | 每候选 <30s；抽样与手工跑 Focus 一致 | 未开始 |
| P3 统计评估（8周） | 双轨采集 → 周报 → stop gate 判定 | 按预注册判据决策 | 未开始 |

每日时序：15:05 选股包运行（10-20min）→ 15:30 候选冻结 → Focus v1 逐候选
分析（30m K线已收盘完整）→ 15:45 合并计划 → 次日执行、收盘后回写 ledger。

## 6. 保密与入库边界（本仓库 public）

- **永不入库**：`价格行为学_分享包_20261004.zip` 及解压目录、其任何源码副本、
  其运行产物（outputs/logs）、样例结果。已在 `.gitignore` 增补对应条目。
- **可以入库**：本计划文档、bridge/裁决/ledger 代码（自有实现）、
  双轨统计结果（不含选股包源码与逐票完整报告原文）。
- 引用选股包结论时只写摘要字段（票码/档位/EV 数值），不复制其报告正文。

## 7. 待确认事项（三层）

**架构层**
1. "我们的分析模型"= Focus v1（本方案默认）。P3 前不加 strategy-engine
   （DeepSeek+Wiki）语义复核层，避免三层叠加分不清功劳。
2. 候选 30m K线取数：倾向只读复用选股包 `kline_unified_fetcher`（省工程+多源容错），
   代价是耦合其快照版本；备选是本仓库自建轻量取数。

**阈值层**
3. stop gate 判据（5 个百分点 / 踏空 40% / 30 笔 / 8 周）是否认可，或先跑 P0-P1
   后再冻结。
4. regime 不明时"不做新仓"是硬规则还是留给人工裁量。

**执行层**
5. paper mode 纯记录 vs 小仓位实盘验证（影响 ledger 成交价字段口径）。
6. 每日 15:05 轮 cron 自动 vs 手动触发。
