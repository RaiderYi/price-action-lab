## 4. 短缓存不是历史（任务书 S2-01 警告落地）

任何供应商"最近 N 天"式短缓存**不得**用于声称多年历史覆盖。接入时
必须：记录实际覆盖期 → 生成 DataSnapshot（S2-07）→ 空缺 slot 与
日历期望比对（GAP_MISSING_SLOT）→ 报告真实覆盖率，不足则缩小结论
范围（任务书 §5.4-2：不生成虚构长历史）。
