## 一句话摘要
楔形引力指标的 V5.0 版本源码——以 FSM 周期引擎为硬规则核心、唐奇安通道为突破边界、三推楔形+H2/L2 为结构来源、高斯引力场为位置校验的四模块实时指标，并通过 9 个不可见 plot 向下游指标 B 输出数据。

## 核心架构（8 大模块）

### 1. FSM 周期引擎（参数组 G0）
- **唐奇安通道**（N=20）：作为"新突破"的边界线
- **三条转移路径**：
  - `rng2nbk`（震荡→新突破）：Path A（实体>1.5×ATR20 + 收盘越前唐奇安 + 价格穿越当前唐奇安）或 Path B（连续3根收盘越唐奇安）
  - `bo2ch`（突破→通道）：当前为突破/新突破状态，振幅≥1.0×ATR20，且出现逆势回调K线
  - `ch2rng`（通道→震荡）：通道状态 + 强实体(>1.0×ATR20) + 极强收盘 + 突破最近分型
- **通道→新突破 无直接路径**：须先经 ch2rng 回震荡，再 rng2nbk
- **重叠度均值**（`avgOlp`，窗口=5）：用于更新各状态置信度
  - 突破/新突破：avgOlp<0.20 + emaSteep → 0.90，否则 0.65
  - 通道：emaSteep + not emaFlat → 0.75，否则 0.50
  - 震荡：emaFlat → 0.80，否则 0.50
- **EMA 传感器**：`emaS3`（3 期 EMA20 斜率）、`emaS10`（10 期）、`emaSteep`（斜率>0.5×ATR20）、`emaFlat`（斜率<0.5×ATR20）

### 2. 三推楔形识别（参数组 G2）
- **上升楔形 `risingWedge`**（偏空）：ph2<pl1<ph1<pl0<ph0 时间序 + 跨度[10,200] + 对称性检查 + 斜率收口
- **下降楔形 `fallingWedge`**（偏多）：对称逻辑
- **校验参数**：空间对称比 [0.25, 2.50]、时间对称比 ≤3.00、最大跨度 200
- **评分体系**：symScore（对称） + convScore（收口/收敛） + spanScore（跨度）
- **`WedgeData` 类型定义**：barA-E、priceA-E、三项评分、isValid 标记——一个楔形对象保存完整状态

### 3. 引力场（参数组 G3）
- **六类引力源**：EMA20(×3)、ph0(×5)、pl0(×5)、ph1(×3)、pl1(×3)、fib50(×4)
- **三日开盘区间重心**（×4）：`gap3H/gap3L` 幅度 > 0.5×ATR14 时追加
- **高斯衰减**：`dist < 2×ATR14` 才贡献，`exp(-0.5×(dist/atr14)^2)`
- **触发阈值**：`gravOK = gScore > i_gThr`（默认 5.0）
- **R² 趋势强度**（窗口=50）：`r2 = correlation(close, bar_index, 50)^2`

### 4. H1/H2/L1/L2 状态机（参数组 G4）
- **两套独立状态机**：`bPh`（多头链，4阶段）和 `sPh`（空头链），各自运行
- **孕线规则**：`insideBar` 不推进计数，但也不退出
- **超时机制**：`i_timeout=25` 根 K 线未完成→重置
- **信息面板显示**：H计数：当前 bPh 阶段（H0/H1/H2/H3），L计数：当前 sPh 阶段

### 5. 结构综合信号
- `longStruct = fallingWedge OR h2`（下降楔形 或 H2）
- `shortStruct = risingWedge OR l2`（上升楔形 或 L2）
- **多头结构分**：楔形 = symScore×0.40 + convScore×0.35 + spanScore×0.25；纯 H2 = 0.55
- **空头结构分**：对称
- **优先级显示**：同时为真时显示 `WEDGE>H2` / `WEDGE>L2`

### 6. 渲染层
- 波段极点（▼/▲ 标记）
- 周期状态标签（NEW BREAKOUT / CHANNEL / TRADING RANGE）
- H1/H2/L1/L2 标签（含 Minor 开关）
- 上升/下降楔形连线（lines + box + label）
- 主图：EMA20(黄)、50%引力位(紫)、唐奇安上下轨(橙)
- 背景色：突破=蓝、通道=青、震荡=橙、新突破=绿

### 7. 数据输出层（9 个 invisible plot，供指标 B 读取）
| # | 字段 | 说明 |
|---|------|------|
| 1 | 周期状态 | 0=突破, 1=通道, 2=区间, 3=新突破 |
| 2 | 趋势方向 | 1=多头, -1=空头, 0=中性 |
| 3 | 置信度 | 0-1 |
| 4 | 楔形信号 | 1=下降楔形(多), -1=上升楔形(空), 0=无 |
| 5 | H2L2信号 | 1=H2, -1=L2, 0=无 |
| 6 | 引力场 | gScore 原始值 |
| 7 | 多头结构分 | structureScoreL |
| 8 | 空头结构分 | structureScoreS |
| 9 | 引力场OK | gravOK 布尔 → 0/1 |

### 8. 警报条件（5 个）
- 上升楔形形成、下降楔形形成、H2 做多触发、L2 做空触发、周期切换

## 与现有知识的冲突
- **FSM 状态 0（BREAKOUT）的存活性**：V5.0 代码中 `bo2ch` 可将状态设为 1（从 0 或 3），但代码初始化是 `fsm=2`（震荡），Path A/B 都是 `fsm==2` 的前置条件——`fsm=0` 依然是"只能进、不能出"的状态（仅通过 `bo2ch` 退出）。这与 V1.5 分析中的"死分支"结论一致，但对 `fsm=0` 的描述在 wiki 中仍有歧义。
- **数据输出层是中性的结构事实**：9 个 invisible plot 的输出本身不做信号判断，只供给指标 B 消费。这与 v3 的"背景引擎→执行引擎通过 input.source 绑定"是不同思路——V5.0 假设指标 B 自行决定如何使用，v3 假设两指标绑定在 Pinescript 层面。
