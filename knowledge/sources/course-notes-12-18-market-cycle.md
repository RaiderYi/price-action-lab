## 一句话摘要
Al Brooks 市场周期理论的完整讲稿——市场永远在「突破 → 窄通道 → 宽通道 → 交易区间 → 突破」的无限循环中运行，每部分有对应的唯一正确交易方式。

## 核心论点

1. **四部分市场周期**：每张图表由四种形态组合而成——突破 (Breakout)、窄通道 (Tight Channel)、宽通道 (Broad Channel)、交易区间 (Trading Range)。多头如此，空头亦如此（对称结构）。

2. **突破 → 通道 → 区间 → 新突破**的循环：
   - 突破是趋势最强的部分，没有明显回调
   - 一旦出现回调，突破阶段结束，通道阶段开始
   - 通道最终减弱，演变成交易区间
   - 交易区间被突破，开始新趋势

3. **80% 惯性法则**（双面应用）：
   - 趋势中：80% 的反转尝试失败 → 只顺势交易
   - 区间中：80% 的突破尝试失败 → 低买高卖刮头皮

4. **回调 = 通道的开始**：回调不仅是趋势中的暂停——它是趋势进入通道阶段的信号。一旦某棒低点低于前一棒低点（多头趋势中），回调已经开始，突破阶段结束。

5. **通道 → 交易区间的过渡信号**：
   - 第一个迹象：限价单逆势交易者（Limit Order Bear/Bull）在前期高/低点赚钱
   - 第二个迹象：止损单逆势交易者（Stop Order Bear/Bull）也开始赚钱 → TR 很快到来

6. **动量交易者 vs 价值交易者**：
   - 动量交易者：突破买入/卖出，高概率 + 高风险（止损远）
   - 价值交易者：回调买入/卖出，低风险 + 较低概率
   - 两者永远并存——一方赚钱需要另一方站在对立面

7. **二元决策框架**：面对任何图表，依次回答四个问题：
   - 趋势还是交易区间？
   - 突破还是通道？
   - 窄通道还是宽通道？
   - 大反转还是小反转？

8. **趋势/波段/腿/回调的层级定义**（无严格边界）：
   - 趋势：占据大部分屏幕的对角线移动
   - 波段：持续 10-20 棒，足以赚取波段利润
   - 腿：1-10 棒的小趋势
   - 回调：最小的一种腿，趋势中的暂停

9. **主要 vs 次要高低点**：
   - 主要更高低点 = 导致强突破创出新高的回撤低点
   - 次要更高低点 = 导致弱反弹的腿中低点，更像交易区间中的腿

## 与现有知识的冲突

- [[fsm-market-cycle]] 的四状态（突破/通道/震荡/新突破）是 Brooks 原始四部分周期的代码化简化版，原始理论中区分了窄通道和宽通道两种子状态，代码实现将其合并为"通道"
- [[market-structure]] 中提到"市场 80% 的时间在交易区间内"，但本课程未给出这个比例——课程中 80% 专指反转/突破失败率，非时间占比
- [[breakout-mechanics]] 的"80% 失败"与本课的 80% 法则一致，但本课同时强调了其双重性（趋势+区间）
