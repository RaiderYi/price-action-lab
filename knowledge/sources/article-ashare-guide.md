## 核心论点

### 1. 数据获取与股票代码
- 使用 [[baostock]] 免费获取全量 A 股历史数据（日线 1990 至今，分钟线 2-3 年）
- 沪市代码 `sh.XXXXXX`（6/688/689 开头），深市代码 `sz.XXXXXX`（0/2/3 开头）
- 支持自动识别前缀

### 2. 关键参数与运行模式
- 周期：5m/15m/30m/60m/d/w/m，分钟线受限于最近 2-3 年
- 资金/风控：`--equity 100000`（初始资金）、`--risk 0.01`（每笔风险 1%）、`--rs 70`（RS 评分阈值）
- 支持命令行回测 + Web 界面（Flask，默认端口 5000）

### 3. A 股特有处理
- ****：后复权（默认，保持价格连续性）> 前复权（历史成本视角）> 不复权（原始价格，有缺口）
- **交易日历**：自动处理早盘 9:30–11:30、午盘 13:00–15:00，节假日自动跳过
- **回测局限性**：未考虑滑点、冲击成本、涨跌停限制、T+1 规则

### 4. 与 BTC 版本的关键差异
| 特性 | BTC 版本 | A 股版本 |
|------|---------|----------|
| 数据源 | Binance API | baostock |
| 数据量 | 单次 ≤1000 条 | 全量历史（1990 起） |
| 交易时间 | 24×7 连续 | 9:30–15:00（有午间断点） |
| 复权 | 不涉及 | 前复权/后复权/不复权 |
| 网络 | 需翻墙 | 国内直连 |
