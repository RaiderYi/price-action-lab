## 一句话摘要
Brooks 价格行为背景引擎 v3 第一阶段——将 V1.5 的双核架构（硬规则 FSM + 软评分）升级为三层加权背景评分引擎，新增趋势强度过滤、三推回撤分析、Playbook 玩法分类三大模块，定位为"背景分类器"，不直接负责入场管理。

## 核心论点

### 架构演进：V1.5 → v3 Phase-1
- **V1.5**：双核架构 = FSM(硬规则) + 楔形/引力场/H2L2(软评分)
- **v3 Phase-1**：三层加权架构 = 位置层(40%) + 阶段层(35%) + 动能层(25%) → 综合背景分 → 否决/冲突/支持判定
- **定位变化**：从"入场过滤"升级为"背景分类器"——提供全局市场上下文，供执行层独立决策

### 三层评分引擎

**第一层：位置层 (Position Layer, 权重 0.40)**
- 将当前价格与 6 个参考位置的距离全部归一化为 ATR 倍数：pivots、Donchian、EMA20、Fib50
- 分类为：at支撑/阻力、near支撑/阻力、区间中部、追价突破、目标位附近
- 满分加分：站在强支撑上(+0.30)、靠近支撑(+0.18)、靠近Fib50(+0.08)
- 满分扣分：区间中部(-0.28)、追价突破(-0.20)、站在阻力前(-0.28)、目标位已近(-0.16)

**第二层：阶段层 (Phase Layer, 权重 0.35)**
- 继承 V1.5 FSM 四状态机（突破/通道/震荡/新突破）
- **v3 新增 5 种过渡检测信号**：重叠度上升(>0.32)、EMA斜率丧失、宽通道(phase=1且olp>0.24且conf<0.72)、楔形、假突破失败(brkFail_EMG)
- 过渡判定：≥2 个信号触发 或 通道+高重叠 或 新突破+假突破失败
- **v3 新增阶段健康分类**：趋势健康(trendHealthy)、趋势弱化(trendWeakening)、双向环境(twoSided)

**第三层：动能层 (Momentum Layer, 权重 0.25)**
- 正向因子：脉冲评分(bodyRatio×0.55 + breakMag×0.45)、趋势健康度(EMA方向+低重叠+无衰竭)
- 负向因子：趋势成熟度(楔形+追价+衰竭棒+目标近)、衰竭风险(假突破失败+楔形+高重叠+目标近)、当前腿弱化(脉冲降+高重叠+EMA丧失+楔形)
- 最终 `momScore = 0.10 + imp×0.30 + health×0.28 - maturity×0.20 - exhaust×0.18 - weakening×0.12`

### v3 新增模块一：趋势强度过滤 (Trend Strength Filter)
- 四维评估：方向棒占比(30%) + 连续同向棒(25%) + EMA侧占比(25%) + 紧密通道(20%)
- 五级标签：弱趋势(≤40) → 中趋势(40-55) → 强趋势(55-70) → 极强趋势(70-85) → 紧密通道(>85)
- 分级惩罚：随强度递增的反转玩法惩罚分，最高 `i_trendMaxPen`(默认25)
- 缺口加成：检测到测量缺口(measured gap)时额外+8惩罚分
- 屏蔽机制：极强趋势(>85)或带缺口的强趋势(>60)可屏蔽全部逆势玩法（`i_trendBlock`）

### v3 新增模块二：三推背景识别 (Triple Push Background)
- 独立枢轴数组（tpLeft=8, tpRight=4），比 V1.5 楔形检测更灵敏
- **回撤分析**：两推之间搜索回撤深度(findPullback)，要求 ≥ 最小深度(默认25%)，理想深度 38%
- **回撤评分**：深度达标各0-50分 + 收敛加分(回撤递减时额外+5分)
- **质量评分**：对称性(35%, 两段间距比) + 收敛性(35%, 腿长度递减) + 动量衰减(30%, 实体缩小)
- **背景权重**：过渡期=1.0、区间边缘=0.8、趋势弱化=0.7、其他=0.3
- **趋势惩罚**：三推方向若与趋势同向，施加趋势惩罚分

### v3 新增模块三：Playbook 玩法分类
5 种玩法状态机，按优先级：
1. **强趋势禁逆势 (5)**：trendBlock 触发时，屏蔽一切反转玩法
2. **区间边缘反转 (3)**：震荡+靠近边界→以限价单思路在边界博弈
3. **过渡期反转 (4)**：过渡信号≥2 或 有三推背景且权重≥0.7
4. **趋势突破延续 (1)**：新突破(phase=3)且目标位未到
5. **顺势回调再入 (2)**：通道(phase=1)且趋势健康
0. **等待 (0)**：以上均不满足

### 综合与否决 (Synthesis & Veto)
- **背景分**：`bgScore = locScore×0.40 + phaseScore×0.35 + momScore×0.25`
- **冲突检测**：多空背景分差 > 0.18 或 得分在中性区(0.42-0.58) 或 双向环境+不在支撑上
- **否决条件**：区间中部+震荡、反向强趋势+低衰竭风险、阻力追价做多、高成熟度/高衰竭风险+目标近
- **背景状态码**：9=否决, 2=多强(≥0.72), 1=多可, -2=空强, -1=空可, 0=中性
- **强趋势约束**：`i_trendBlock` 开启时，强趋势额外否决同向三推

### API 导出
v3 通过 `display.data_window` 导出 30+ 个 API 变量供执行层联动，包括：各层分项分、综合背景分、阶段状态/方向/置信度、背景支持/冲突/否决标志、趋势强度/惩罚/屏蔽、Playbook状态、三推各项指标、API版本号(3.1)和就绪标志。

## 与现有知识的冲突
- V1.5 的 `three-push-wedge` 在 `isPH`/`isPL` 确认柱上触发，评分维度为对称/收口/跨度。v3 的 `triPushDetect` 使用独立枢轴数组+回撤分析，质量评分维度改为对称(35%)+收敛(35%)+动量衰减(30%)，完全独立于 V1.5 楔形检测。两者可共存，但 v3 的三推检测更精细、参数更多。
- V1.5 的 FSM 仅以 `avgOlp`、`emaSteep`、`emaFlat` 更新置信度，v3 在此基础上新增了完整的过渡检测系统和阶段健康分类，将「市场在变」的模糊边界量化。
- v3 明确将自身定位为「背景分类器」而非「入场过滤器」——这意味着 v3 输出的背景状态码/Playbook/否决标志应由下游执行层（Phase-2）解释和消费，而非直接生成入场信号。
