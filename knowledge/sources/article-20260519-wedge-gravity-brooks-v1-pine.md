## 核心论点

### 1. 架构概览：从双核到 Brooks 增强

V1.5.2 在 V1.4「双核架构」（硬规则 FSM + 软评分量化）基础上显式融入 Brooks 四步背景分析，形成**三核协同**：

```
OHLC → FSM 周期引擎 → 楔形检测 → 引力场 → H2/L2 计数 → 信号评分
                                  ↓
              Brooks Step1 (S/R) → Step2 (阶段) → Step3 (动能) → Step4 (否决)
```

### 2. 九大模块详解

| 模块 | 函数/区块 | 核心逻辑 |
|------|----------|---------|
| **模一A: FSM 传感器** | EMA斜率 + 重叠度 + 唐奇安通道 | 3 个传感器为 FSM 提供状态转换数据 |
| **模一B: 引力场** | `f_gauss()` 高斯衰减 | 7 种关键位加权求和 → `gScore` → `gravOK` |

| **模三: H2/L2 状态机** | 4 阶段计数 | 含孕线免疫 + 超时重置(25 bar) |

| **FSM 策略约束** | `allowLong`/`allowShort` | 按周期状态决定允许的交易方向 |

### 3. Brooks 四步法的代码实现

**Step1 支撑阻力** (`ctx1_score`，权重 0.52)：基于 7 种最近关键位的距离（ATR归一化）评分。附加 MM 目标距离和整数关口磁吸。

**Step2 市场阶段** (`ctx2_score`)：直接复用 FSM 状态 + 额外的「过渡」检测（EMA 由陡→平 + 唐奇安宽度扩张）。分值区间：震荡 0.52、过渡 0.46、通道 0.76、突破 0.84。

**Step3 动能健康** (`ctx3_score`)：重叠度健康(0.38) + 均线斜率(0.18~0.32) + 紧急逃生否(0.26) + 实体强度(0.04~0.12)。

**Step4 一票否决**：两个硬否决条件——TR 上区禁多/下区禁空 + 紧急逃生时禁止顺势追价。

### 4. V1.5.2 新增机制（相对于 V1.5 分析文档）

- **信号分级 ABC** (`lGrade`/`sGrade`)：≥0.80→A, ≥0.60→B, 否则 C。可选 `i_gradeMin` 过滤。
- **结构优先级**：楔形 > H2/L2，冲突时楔形胜出。
- **趋势/反转分离**：趋势信号侧重动量，反转信号侧重位置。
- **关键位分层**：Tier-1（ph0/pl0/donchH/donchL）vs Tier-2（ph1/pl1/ema20/fib50）。
- **FSM 策略约束**：突破阶段仅顺势、通道顺势为主+边界逆势剥头皮、TR 仅边界反向入场。
- **force_overlay + yloc**：锚定柱体，减轻缩放导致的 K 线脱节。
- **整数关口磁吸**：Brooks Step1 中的 round number detection。
- **唐奇安宽度扩张**：过渡检测的辅助信号。
