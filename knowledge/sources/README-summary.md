## 一句话摘要
将 Al Brooks 价格行为方法论量化为可编程信号和评分系统，实现 MES 5 分钟级别的半自动辅助决策（含回测、实时面板和 TradingView 指标）。

## 核心论点

### 1. 7 大入场信号（按优先级排序）
1. **SPB 限价单** — 强回调（Strong Pull Back）状态下在 H1/H2 挂限价单，胜率最高
2. **EMA 双测** — 两次测试 EMA 后趋势恢复时入场
3. **H1/H2 回调** — 牛市趋势中回调做多（H1/H2），熊市中反弹做空（L1/L2）
4. **微型 HL 双底 / LH 双顶** — Horn（喇叭口）形态，最频繁的剥头皮信号
5. **BTC/STC** — 买在收盘 / 卖在收盘，需要连续 2 根趋势 K 线确认
6. **楔形反转** — 三推结构形成的楔形顶/底反转
7. **TR 逆势** — 交易区间极值第 4 次反转（80/20 规则）

### 2. 4 大市场状态与操作原则
| 状态 | 操作原则 |
|------|----------|
| 牛市趋势 | 只做多，买 H1/H2 回调 |
| 熊市趋势 | 只做空，卖 L1/L2 反弹 |
| SPB（强回调） | 用限价单，每次回调都是机会 |
| 交易区间（TR） | 逆势操作极值，等第 4 次反转 |

### 3. RS 评分系统（10+2 维度，≥70% 才入场）
10 个正向维度各 ±5 分，2 个加成/惩罚维度：
- 趋势 Bar 一致性、收盘位置强弱、Tick 缺口、实体缺口、连续同向 Bar
- OHLC 趋势递进、无重叠、与 HTF 方向一致（±10）、价格控制（+5）、时间控制（+5）
- 晚期腿惩罚（-20）

### 4. 风控参数
- 每笔风险：1% 资金
- 日亏损上限：-4R
- 每日最多 6 笔
- 持仓超 20 根 Bar 无进展则强制平仓

### 5. TradingView 指标生态
项目配备了完整的 Pine Script 指标系列（Wedge-Gravity V1.4 → V2 Master），将 Brooks 四步分析背景法整合到图表中。
