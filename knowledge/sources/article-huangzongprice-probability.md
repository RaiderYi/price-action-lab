# Brooks 概率表

## 元信息
- **作者**：huangzongprice（整理/编译自 Al Brooks 多本原著）
- **日期**：未标注
- **原始位置**：`raw/articles/huangzongprice/概率.txt`
- **内容性质**：Al Brooks 价格行为学中的概率统计规则汇编，按概率从 90% 到 10% 降序排列

## 一句话摘要

Brooks 价格行为学中所有量化概率规则的完整汇编——从 90% 的波段交易机会到 10% 的突破模式，是交易决策的概率数学基础。

## 核心内容

本文按概率层级系统整理了 Brooks 原著中散布的概率统计规则，共覆盖 **90% / 80%(85%/75%) / 70% / 60% / 50% / 40% / 30% / 20%(25%) / 10%** 九个概率档位，约 40+ 条规则。

### 概率层级总览

| 概率 | 核心主题 | 规则数 |
|------|---------|--------|
| **90%** | 交易区间普遍性 + 趋势日 EMA 行为 | 5 |
| **80%/85%/75%** | 80/20 法则 + 缺口 + 趋势回撤规律 | 5 |
| **70%/75%** | 测量走势 + 头皮交易 + 高潮后行为 | 8 |
| **60%** | 趋势入场（高2/低2/旗形/突破回调）+ 反转入场 | 18+ |
| **50%** | 开盘反转 + 高潮跟进 + 突破模式 | 5 |
| **40%** | MTR 波段利润 | 2 |
| **30%/35%** | MTR 盈亏分布 + 惊喜棒反向 | 3 |
| **20%/25%** | 80/20 成功侧 + 首棒极值 | 6 |
| **10%** | 突破模式时间占比 | 1 |

### 最重要的五条元规则

1. **90% K线在交易区间中** — 市场绝大多数时间在 TR，趋势是稀有事件
2. **80/20 法则** — 趋势中 80% 反转失败 / TR 中 80% 突破失败
3. **99.5% 趋势日到达 EMA** — 无论趋势多强，日内一定会触及 EMA
4. **90% 每天有一次波段机会** — 信号棒良好、≥2腿、RR≥2:1、持续 1-2 小时
5. **60% 概率即足以盈利** — 只要回报≥风险，60% 胜率的架构可以稳定盈利

## 与现有知识的冲突

- **无明显冲突**。本文的概率数据与 [[forty-sixty-rule]] 的核心假设（90% 时间概率在 40%-60%）互补——后者是理论基础，前者是实践数据点。
- **待验证**：部分概率数据来自 Brooks 特定时空（2010s 美股指数期货），跨市场（A股/BTC）适用性待验证。
