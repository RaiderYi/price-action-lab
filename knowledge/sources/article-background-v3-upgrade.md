## 一句话摘要
将背景层从"能不能做"的过滤器升级为"应该找什么信号"的交易机会分类器（Playbook Engine），新增趋势过滤/区间增强/SR环境/Playbook/三推背景识别 5 大模块。

## 核心论点

### 设计目标
背景层 v1/v2 已有位置分析、市场阶段识别、动能健康度、一票否决。但偏"过滤器"角色，不够清晰地告诉交易者**当前应重点寻找什么类型的信号**。v3 将其升级为**交易机会分发器 / 背景玩法引擎**。

### 三大原则
1. **背景先于执行**：背景描述环境→识别玩法类型→决定哪类结构有资格进入执行候选池
2. **三推保留在背景层**：三推 ≠ 入场信号，而是「背景成熟度 / 过渡证据 / 玩法分类的重要证据」
3. **执行层仍保留结构确认**：更严格的入场级确认（信号棒过滤、确认K线、入场止损目标）

### 五大新增模块
| 模块 | 功能 | 核心输出 |
|------|------|---------|
| A. 趋势强度过滤 | 判断趋势是否强到"不适合做反转" | `trendBlock`, `tightChannel`, `gapImpulse` |
| B. 区间增强识别 | 明确价格在区间上沿/下沿/中部 | `rangeZone`, `rangeEdgeFlag`, `rangeMiddleFlag` |
| C. S/R 强弱环境 | 升级为 Major/Minor S/R 环境识别 | `majorResistanceNear`, `srConfluenceCount` |
| D. Playbook 背景玩法 | 当前应优先寻找哪类信号（核心模块） | `playbookState` (0-5), `playbookText` |
| E. 三推背景识别 | 三推作为成熟度/过渡证据 | `triPushQuality`, `triPushBackgroundWeight` |

### Playbook 六种状态
```
0 = 等待/观望
1 = 趋势突破延续 → 优先看突破后 follow-through
2 = 顺势回调再进入 → 优先看 H2/L2
3 = 区间边缘反转   → 优先看假突破失败、边缘楔形
4 = 过渡期反转     → 优先看楔形、三推衰竭、反转确认棒
5 = 强趋势禁逆势   → 仅顺势信号，反转结构全部降权
```

### Playbook 生成优先级（固定顺序）
1. 极强趋势拦截 → 2. 区间判断 → 3. 过渡判断 → 4. 新突破判断 → 5. 通道判断 → 6. 否则等待

### 三推在背景层的重新定位
- 三推 ≠ 入场信号
- 三推 = **成熟度证据 / 过渡证据 / Playbook 切换证据**
- 背景层保留：三推动作、回撤验证、趋势惩罚、概率评分、屏蔽判断
- 背景层不放：入场线、止损线、T1/T2 目标位、磁铁线、具体交易触发条件

### 推荐实施顺序
1. 升级设计（定模块边界与输出字段）
2. 优先实现趋势过滤模块
3. 实现 Playbook 模块
4. 三推背景识别纳入成熟度与玩法切换
5. 执行层消费新的 playbookState

### 最终方法论总结
**核心升级不是"更多 veto"，而是把背景层从风险过滤器升级成交易机会分类器。** 三推必须保留，其职责定位为背景成熟度证据与玩法切换依据，不是直接交易触发器。
