# TradingView

## One-sentence Definition
The world's largest social financial charting platform with Pine Script programming language for custom indicators and strategies.

## Key Features
- Pine Script: proprietary chart scripting
- Social: share trading ideas and strategies
- Backtesting: built-in strategy tester
- Multi-market: stocks, futures, forex, crypto

## PA System Integration
- Wedge Gravity indicator series (V1.4 -> V2 Master)
- Brooks Context 4-step analysis panel
- Real-time signal scoring display
