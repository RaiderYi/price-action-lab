# MES (Micro E-mini S&P 500)

## One-sentence Definition
Micro E-mini S&P 500 Index Futures -- the primary trading instrument for the Brooks Price Action day trading system, $0.50 per index point.

## Specifications
- Exchange: CME Group
- Contract: $0.50 x Index point
- Tick: 0.25 point = $1.25
- Hours: Nearly 24h (Sun 18:00 - Fri 17:00 ET)
- Primary session: 9:30-16:00 ET

## In PA System
- Core instrument for huangzongprice strategy
- Main timeframe: 5-minute candles
- Entry refinement: 1-minute candles
