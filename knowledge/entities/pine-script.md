# Pine Script

## One-sentence Definition
TradingView's proprietary scripting language for technical indicators, strategies, and drawing tools.

## Key Features
- Forward calculation on historical data (anti-repainting)
- Built-in ta.* indicator library
- Alerts, strategy backtesting, chart plotting
