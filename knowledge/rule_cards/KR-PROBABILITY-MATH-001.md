## 审核对象

原文（L31）：**"70% 胜率需回报≥风险才打平（头皮交易）"**

## 数学复核（无成本二项模型）

设胜率 p，盈亏比 b（reward/risk），无成本：
```
期望 = p·b − (1−p)
打平 ⇔ b = (1−p)/p
```
- p = 0.70 → **b ≈ 0.4286**（即约 0.43:1，回报只需风险的 ~43% 即打平）
- 原文"回报≥风险"（b ≥ 1）在 p=0.70 下给出期望 = 0.7 − 0.3 = +0.4R，
  是**充分盈利**条件，不是打平条件

结论：原条目数学错误（把充分条件写成必要条件）。
任务书 §5.3 已裁定同一结论（"p=70% 时 b≈0.4286；说明知识库相关
'至少 1:1 才打平'不能直接作为数学规则"）。

## 附带条件（原文遗漏，工程使用时必须补充）

1. 上述为**无成本**模型；A 股现实有佣金/印花税/滑点，b 的打平点上移；
2. 二项模型假设亏损固定 1R——实际存在跳空超损（>1R）、超时退出（非±R）
   结果，任务书 §5.3：`E[R_net] = Σ P(k)·E[R_net|k]` 才是一般式；
3. 头皮交易（scalp）语境的 70% 是 Brooks 对特定形态的**先验转述**，
   未在本系统样本上校准 → probability_status=uncalibrated_prior。
