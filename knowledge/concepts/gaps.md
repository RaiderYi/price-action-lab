# 缺口体系

## 一句话定义
Brooks 将「缺口」的概念大幅扩展：当前价格与任何支撑/阻力之间的空间都是缺口——它不仅限于传统的跳空，还包括实体缺口、突破回撤缺口、均线缺口、微型缺口等。

## 核心要点

### Brooks 的缺口定义
- 缺口 = 当前价格与任何支撑/阻力位之间的空间
- 任何棒线的高、低、开、收都可以形成缺口
- 缺口可以非常小（微型缺口）

### 传统缺口类型
1. **突破缺口（Breakaway Gap）**：趋势初期的缺口
2. **测量缺口（Measuring Gap）**：趋势中部的缺口 → 通常导致测量移动
3. **耗尽缺口（Exhaustion Gap）**：趋势末期的缺口 → 很快被回补
4. 缺口被回补前，无法确定类型；只有事后才知道
5. 在交易区间中的缺口通常毫无意义

### 实体缺口（负缺口 / Negative Gap）
- 突破点与回调之间的轻微重叠
- 强势标志，但不如完全缺口可靠
- 经常导致测量移动

### 均线缺口棒（MAG — Moving Average Gap Bar）
- 趋势在均线一侧运行 20+ 棒后，首次有棒完全穿越均线
- **多头趋势 MAG**：空头强到足以把棒推到均线之下 → 通常引出趋势最后一涨（最后旗形）→ 40% 的主要趋势反转成功，60% 成为多头旗或交易区间
- **空头趋势 MAG**：多头强到足以把棒推到均线之上 → 通常引出趋势最后一跌 → 40% 反转成功
- MAG 后通常还有一段顺势行情（测试均线缺口）

### 耗尽缺口
- 趋势运行 10-20 棒后出现的大趋势棒
- 通常是 20 棒中最大的棒（最大实体）
- 缺口被回补后确诊为耗尽缺口
- **多头耗尽缺口**：第一目标位是买入高潮棒底部 → 空头尝试向下测量移动
- **空头耗尽缺口**：第一目标位是卖出高潮棒顶部 → 多头尝试向上测量移动
- 60% 的情况趋势结束（至少暂停），40% 是更强趋势的开始

### 微型缺口（Micro Gap）
- 每一根趋势棒都是一个突破尝试 = 一个缺口
- 观察前后棒不重叠即为缺口
- 缺口保持开放 → 趋势强
- 缺口被回补 → 趋势变弱

### 开盘缺口棒（Gap Open Bar）
- 一棒的开盘价高于或低于前一棒的收盘价
- 多头棒后向上跳空 → 延续上升；向下跳空 → 可能逆转
- 空头棒后向下跳空 → 延续下跌；向上跳空 → 可能逆转

### 台阶（Stairs）
- 缺口被回补 → 突破演变为通道（重叠形成台阶）
- 通道可能很快进入交易区间
- 多头在空头趋势中开始刮头皮赚钱 → 空头趋势即将结束

## 实战应用
在趋势中关注突破点和回调之间的缺口——只要缺口不补，趋势就还有空间。当缺口开始被回补（台阶出现），趋势正被削弱，准备进入交易区间或反转。
