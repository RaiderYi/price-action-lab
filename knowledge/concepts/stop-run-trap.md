# 止损陷阱

## 一句话定义
当止损被触发后，市场有50%的概率反转回原方向——止损触发往往不是趋势的确认，而是对双方力量的一次测试。

## 核心要点

### 50% 止损失败规则
- 任何时候止损被触及，市场继续朝突破方向走的概率是 **50%**
- 另外 **50%** 的概率：突破失败，市场反转回原方向
- 这"只是对双方力量的一次简单测试"（Simply test of strength of 2 sides）

### 实践含义

| 场景 | 应对 |
|------|------|
| 你的止损被触发 | 不要恐慌——50%可能只是陷阱，观察是否反转回来 |
| 你被止损出局 | 如果背景仍支持原方向，准备再次进场 |
| 你看到别人的止损被触发 | 这是一个潜在的逆势入场机会——但需要等待确认 |
| 使用紧止损 | 第一个卖出信号经常失败——如果止损出局，再次卖出 |

### 紧止损的风险
- "如果使用紧止损，第一个信号经常失败"
- "一般来说，只要风险较小，将止损放在信号棒顶部上方就是错误的"
- 最好使用**更宽的止损点**，向上移动，或向左寻找其他止损点

### 止损陷阱的成因
- 市场常常出现方向错误的强劲走势——这是很常见的（Markets often have strong move in wrong direction）
- 强势交易者利用止损触发来获取更好的价格：
  - 空头在LH上方卖出，让弱多头止损出局 → 然后市场反转下跌
  - 多头在HL下方买入，让弱空头止损出局 → 然后市场反转上涨
- 止损触发 → 弱手持仓出局 → 强手接手 → 市场反转

### Brooks 的关键建议
> "如果在5棒内被止损出局，并且有另一个卖出信号——再次卖出"
> "强势空头依靠在信号棒上方的止损"
> "当任何止损被触及时，50%的机率是陷阱，然后反转下跌"

### 盈亏平衡止损规则
- 第一次回调测试入场价且创出新低/新高 → 可以接受
- **第二次测试入场价 → 必须全部退出**（Do not let breakeven stop get hit twice）
- 第一次测试后的再次测试意味着市场在告诉你：你的方向可能错了

## 与相关概念的关系
- [[emergency-exit]]：止损陷阱是止损设置中必须考虑的反向风险——过紧的止损反而增加被陷阱套出的概率
- [[price-is-truth]]：被止损后否认市场（"我没错，市场错了"）→ 违反"价格即真相"
- [[eighty-percent-rule]]：止损陷阱与80%法则的关系——在TR中，80%的突破失败；止损触发 = 一个小突破，其失败概率也与市场状态相关
- [[major-trend-reversal|Major Trend Reversal]]：止损陷阱后的反转 → 小反转（回到原趋势）还是大反转（MTR）？需要根据卖压/买压来判断

## 实战应用
1. **设置止损时**：不要放在信号棒正上方/下方——那是所有人都在看的地方，最容易被"扫止损"
2. **被止损后**：不要立即放弃交易方向——等待1-2根棒，看是否反转回来
3. **如果反转回来**：重新进入（特别是如果有一个新的信号棒确认）
4. **如果继续突破**：接受止损，这是那50%的正确止损
5. **盈亏平衡后**：第一次被测试可以继续持有，第二次被测试必须全出

## 矛盾与待验证
- "50%"是在什么市场状态下的统计？在强趋势突破中，止损失败率可能远低于50%；在TR中远高于50%
- "把止损放在信号棒上方是错误的"——但这与使用信号棒作为止损参考的常规做法矛盾。Brooks 的意思是：当风险过小时才是错误的；如果信号棒上方提供了合理的风险空间，那就是正确的止损位
