# 崩溃行情 (Crash Patterns)

## 一句话定义
崩溃是 K 线极大（远超正常范围）、动量不可持续的价格暴跌或暴涨——Brooks 的核心建议：**大多数交易者不应交易崩溃行情**。

## 核心要点

### 崩溃的定义
- Brooks 的崩溃定义是操作性的：**K 线的大小使止损过远 → 风险 > 3% 账户 → 不应交易**
- 崩溃 ≠ 普通下跌趋势——区分在 K 线规模
- 崩溃可以有多种时间框架：5 分钟 K 线的日内崩溃 / 日线 K 线的金融危机崩溃

### 崩溃中的 K 线特征
- 实体极大——远超出过去 20 根 K 线的 2-3 倍范围
- 连续出现——不是一根大棒后回调，而是连续多根大棒
- 无反弹/无回调——紧通道或微通道中快速推进
- 速度异常——市场几乎直线运动，无时间做出决策

### 崩溃 = 极端高潮
Brooks 将崩溃归类为**极端连续高潮**：
- 崩溃向上（Crash Up）= 连续买入高潮 → 最终 Blow Off Top
- 崩溃向下（Crash Down）= 连续卖出高潮 → 最终劳损性底部

### Brooks 的崩溃交易规则

| 规则 | 说明 |
|------|------|
| **大多数人不应该交易** | K线过大 → 止损过远 → 风险超标 → 放弃 |
| **崩溃 = 高潮** | 向下崩溃 = 卖出高潮，向上崩溃 = 买入高潮 |
| **不要卖空向上崩溃** | 回调可能很浅、很快，卖空风险极高 |
| **不要买入向下崩溃** | 即使最终反转，过程可能是V形——无入场点 |
| **等待 TR 出现** | 崩溃后市场通常进入 TR——在 TR 中找入场点 |
| **新手必须等待** | 大棒 = 快速运动 = 更少决策时间 = 更多错误 |

### 崩溃的后续演化

```
崩溃 → 暂停（1-3 根 K线的短 TR）
      → 演变方向 A：突破模式 → 继续崩溃方向
      → 演变方向 B：TR 扩张 → 最终反转
      → 演变方向 C：V 形反转 → 崩溃后直接反向运动
```

### 历史性案例
百科全书收录的历史崩溃实例：
- **2010 Flash Crash**（闪电崩盘）：5 分钟 K 线极大——Brooks 标注"大多数人不应交易"
- **金融危机崩溃**：K 线极端放大——到收盘时，早盘的大棒已经显得"小"了
- **12:13 PM 28 点反转**：Flash Crash 日，市场在 1 分钟内反弹 28 点——崩溃后不一定继续崩溃

## 与相关概念的关系

- [[climax]]：崩溃是高潮的极端形式——将 climax 的"不可持续"推到物理极限
- [[consecutive-climaxes]]：崩溃通常是连续高潮的最后一腿，是所有买单/卖单被同时消耗的结果
- [[buy-vacuum-sell-vacuum]]：崩溃后的真空效应最剧烈——崩溃消耗了所有同向流动，创造巨大的反向真空
- [[protective-stops]]：崩溃中保护性止损的核心矛盾——止损必须放得足够远，但放得够远又超过 3% 风险上限
- [[position-sizing]]：崩溃中的仓位规模 = 0（不交易）——或极小的"我不在乎"仓位
- [[huge-volume-reversals]]：日线图上的崩溃 + 巨量 = 巨量反转模式

## 实战应用

1. **识别**：K 线实体 > 过去 20 根平均的 3 倍 + 连续 3 根以上 → 崩溃模式
2. **不交易**：如果当前 K 线尺寸意味着止损超过 3% 账户 → **不交易**
3. **如果一定要交易**：
   - 使用极小的"我不在乎"仓位（0.5-1% 风险）
   - 崩溃向下的唯一安全买入：等三根多头棒 + 连续反弹后的回调入场
   - 崩溃向上的唯一安全卖空：等连续多头棒出现大的尾线（tail on top）
4. **崩溃后**：崩溃后的第一天通常也是大棒日——即使方向相反——所以第二天也需要小心

## 矛盾与待验证
- Brooks 说"大多数人不应该交易崩溃"但也提供了崩溃交易规则——这两者之间的界限是模糊的
- "K 线极大"缺乏精确的量化标准（多少倍 ATR？）
- 加密货币市场的日常波动率可能已接近 Brooks 时代的"崩溃"水平——需要跨市场校准
