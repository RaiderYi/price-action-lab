# Globex（夜盘交易区间）

## 一句话定义
期货市场在前一日收盘后到当日开盘前的电子盘交易区间——90% 概率当日会突破此区间。

## 核心要点
- **定义**：Globex = CME 的电子盘交易时段。在 Brooks 语境中，特指前日收盘 → 当日开盘之间的盘前/夜盘交易形成的价格区间
- **90% 规则**：90% 的交易日会突破 Globex 区间的高点或低点
- **区间大小影响**：
  - **小区间**（<5 点）：突破概率更高，但突破后可能双向来回
  - **大区间**：日内交易可能完全在 Globex 区间内运行，突破概率降至 <90%
- **磁力效应**：Globex 高点和低点在日内成为磁力位，价格倾向于回归测试
- **趋势信号**：突破 Globex 区间且有力跟进 → 当日趋势方向确认

## 与相关概念的关系
- [[breakout-mechanics]]：Globex 区间突破是日内突破交易的最早信号来源
- [[support-resistance|Support/Resistance]]：Globex H/L 是当日最重要的初始支撑阻力位
- [[trend-from-the-open]]：突破 Globex H 并持续上行 → 开盘趋势日（多）；突破 Globex L 并持续下行 → 开盘趋势日（空）
- [[measured-move]]：Globex 区间突破 = 潜在量度目标（区间高度投影）

## 实战应用
开盘前先标记 Globex 高点和低点。开盘后观察价格相对这两个位置的行为：强力突破 + 回调不破 → 当日趋势方向确认；反复测试不破 → 可能是 TR 日。

## 矛盾与待验证
- **A 股适用性**：A 股无夜间连续交易的 Globex 概念。最接近的类比是"集合竞价区间"（9:15-9:25），但机制不同（集合竞价非连续交易、无持仓可转移）。此概念主要用于理解 Brooks 原版框架，A 股实战中需替换为开盘区间/昨日收盘价。
- **90% 规则在低波动市场的表现**：Brooks 的 90% 基于 ES 期货数据，其他品种/市场可能不同。
