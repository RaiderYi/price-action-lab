# 突破测试 (Breakout Test / BO Test)

## 一句话定义
市场突破某个价位后，往往会回测该突破点——该价位从此成为 S/R 磁力位。

## 核心要点

### 基本原理
- **突破后回测**：市场突破支撑或阻力后，价格会回头测试那个被突破的价位
- **角色互换**：突破后支撑变阻力、阻力变支撑
- **磁力效应**：突破点成为磁力位，吸引价格回归

### 多头突破后的 BO Test
- 多头突破后，市场常抛售回到入场价附近
- 在入场价上方买入的多头急切想再买——用限价单买，或用止损单在反转向上时买
- **入场价=支撑**：原入场价位成为支撑（磁力位）
- **信号棒低点=支撑**：买入信号棒的低点也是支撑位

### 空头突破后的 BO Test
- 做空后，市场常反弹回入场价
- **入场价=阻力**：空头在此再次卖出——用限价单或止损单在反转下跌时卖
- **信号棒高点=阻力**：卖出信号棒的高点也是阻力位

### BO Test 的驱动力量
三个群体共同推动 BO Test：
1. **获利了结者**：已经获利的一方部分平仓→反向推动价格回测
2. **被套者的自救**：在突破前错误方向持仓的人，利用测试点盈亏平衡退出
3. **加仓者**：趋势中加仓的交易者，利用测试点重新入场或扩大仓位

### BO Test 交易规则
- 买入入场棒低点（支撑）处的反转向上
- 买入信号棒低点（支撑）处的反转向上
- 卖出入场棒高点（阻力）处的反转下跌
- 卖出信号棒高点（阻力）处的反转下跌
- 用限价单（在测试点上挂单）或止损单（等反转确认后入场）

## 与相关概念的关系
- [[support-resistance|Support/Resistance]]：BO Test 解释了 S/R 形成的一种核心机制
- [[breakout-mechanics]]：BO Test 是突破的后续确认或失败
- [[scale-in-dynamics]]：加仓者盈亏平衡退出是 BO Test 的重要驱动力
- [[fifty-percent-pullback]]：50%回撤常是 BO Test 的另一种表现形式

## 实战应用
每当看到强势突破，预期市场将回测突破点。在回测时用限价单在突破点上方（多头）或下方（空头）挂单，或等反转棒确认后入场。如果回测失败（未到达突破点就恢复趋势），说明趋势极度强劲。
