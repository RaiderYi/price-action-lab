# 保护性止损 (Protective Stops)

## 一句话定义
保护性止损是防止单笔亏损失控的防御机制，永远必须在市场中架构（而非仅存在于头脑中），止损的大小决定头寸大小。

## 核心要点

### 止损的哲学
- 亏损是交易的一部分，止损防止亏损过多
- 止损决定头寸大小（以损定仓）
- 如果没有保护性止损 → 在最差价位"受不了"时离场
- 止损保护你免受黑天鹅

### 止损类型

| 类型 | 方法 | 适用场景 |
|------|------|----------|
| **价格行为止损** | 放在信号棒下方/多头腿底部下方 | 最常见，适合初学者 |
| **宽止损** | 放在主要低点/高点下方/上方 | 波段交易，给前提时间 |
| **金额止损** | 固定金额/百分比 | 简单但不够灵活 |
| **追踪止损** | 随趋势推进提升止损 | 趋势交易 |
| **盈亏平衡止损** | 移到入场价 | ⚠️ Brooks认为无数学基础 |
| **S/R止损** | 基于测量移动/支撑阻力 | 目标区域附近 |

### 价格行为止损（最推荐）
- 信号棒可能是多头腿开始 → 止损在信号棒下方
- 信号棒可能是更多回调 → 止损在多头腿底部下方
- 多头趋势 → 止损在最近的主要更高低点下方
- 买入收盘多头趋势 → 止损在强势多头腿底部下方
- 空头趋势 → 止损在最近的主要更低高点上方

### 止损选择原则
1. **窄止损**：损失少但更频繁被击中
2. **宽止损**：损失次数少但每笔损失大
3. 两者多次交易后总结果相同 → 选择适合自己的
4. 宽止损的目的：给前提成功的时间，绝不让止损被击中
5. 当止损距离是正常2倍时 → 仓位必须是正常的一半（以损定仓）

### 即使止损被击中...
- 止损被击中 → 创造突破和二次入场机会
- 被止损不是大问题 → 如果前提仍有效，再次入场
- 50%几率止损被触及后趋势恢复 → 陷阱
- 前提不再有效时 → 在止损被击中前主动退出

### 止损与市场环境

| 环境 | 止损策略 |
|------|---------|
| **强趋势** | 追踪止损，主要低点下方 |
| **TR** | 宽止损（两个合理止损点，用较高的） |
| **窄TR** | 不交易（止损/限价单都难赚钱） |
| **通道** | 通道演化中 → 止损在主要低点下方 |
| **反转架构** | 小信号棒→用大止损（风险小但概率低） |

### 重要禁忌
- 不要只使用小止损（紧止损导致刮头皮亏损）
- 不要在没有保护性止损的情况下交易
- 不要因为止损被击中就放弃（前提有效→再次入场）
- 不要试图在止损被击中后"扛单"——那是把刮头皮变成波段

## 实战应用
每次入场前先确定止损位置，然后根据止损距离计算仓位大小。趋势中追踪止损到最近的腿底部下方，TR中用宽止损并降低仓位。
