# 反转失败即顺势

## 一句话定义
当反转信号被否定时，原趋势方向获得最强确认——失败的反转是最可靠的顺势信号。

## 核心要点
- 反转失败 = 市场对"改变方向"投了否决票 → 原趋势获得加强
- 反转失败比普通顺势信号更可靠：因为它通过了双重检验（方向投票 + 反转否决）
- Brooks 原文："a failed reversal is a great with-trend setup"
- 两次反转失败（双重失败）= 原趋势几乎必然延续一段可观距离

## 与相关概念的关系
- [[reversal-test]]：测试失败 = 反转失败 = 触发此概念
- [[eighty-percent-rule]]：趋势中 80% 的反转尝试会失败——大部分反转尝试本身就是顺势入场机会
- [[final-flag]]：最终旗形突破后如果回撤失败→回到旗形内→原趋势恢复而不是反转
- [[breakout-mechanics]]：突破失败 = 反向信号，与反转失败同理
- [[traps-in-out]]：反转失败制造陷阱——追反转的人被套，被迫平仓进一步推动原趋势
- [[major-trend-reversal|Major Trend Reversal]]：MTR 信号出现但被否定 = 强烈的 MTR 失败 = 顺势延续

## 实战应用
看到反转棒/反转架构后：
1. 不急于入场（等待测试）
2. 如果反转测试失败，反转棒低点被突破 → 立即入场顺势方向
3. 止损设在反转棒极端稍外侧
4. 这笔交易的概率远高于普通顺势入场——因为逆势交易者的止损单会成为推手
