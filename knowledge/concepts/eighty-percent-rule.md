# 80% 法则

## 一句话定义
市场倾向于做它一直在做的事情——趋势中 80% 的反转尝试失败，交易区间中 80% 的突破尝试失败。

## 核心要点

### 双面法则
| 市场状态 | 80% 什么会失败 | 策略含义 |
|----------|---------------|---------|
| 趋势 | 反转尝试 | 不要逆势交易——那些"好看的信号棒"、"微型双底"、"多头内包棒"大概率只是回调，不是反转 |
| 交易区间 | 突破尝试 | 不要追突破——在区间边界低买高卖；第3-4次边界测试时逆势入场胜率高 |

### 市场惯性（Market Inertia）
- Brooks 的惯性原理：市场具有惯性，倾向于继续做它一直在做的事情——就像预测明天天气的最佳方法是观察今天天气
- 未看到的右侧K线很可能延续左侧已形成的形态
- **趋势中的惯性**：市场不断尝试反转，但 80% 的反转尝试失败
  - 在空头趋势中：每次反转尝试 → 形成较低高点 → 空头旗 → 继续下跌
  - 在多头趋势中：每次反转尝试 → 形成较高低点 → 多头旗 → 继续上涨
  - 反转成功是例外（20%），需要强势反转棒 + 跟进确认
- **区间中的惯性**：市场不断尝试突破，但 80% 的突破尝试失败
  - 突破失败 → 返回区间内 → 再次测试另一边界
  - 成功的突破是少数（20%），需要大实体趋势棒 + 跟进确认
- 惯性 = 市场抗拒改变的内在属性；80% 法则是其统计表现

## 与相关概念的关系
- [[market-structure]]：趋势或区间的判断是应用 80% 法则的前提
- [[breakout-mechanics]]：80% 的突破失败 = 区间惯性；20% 成功 = 新趋势
- [[fsm-market-cycle]]：80% 法则在周期的不同阶段以不同形式表现
- [[channel-to-trading-range]]：80% 法则解释了为什么逆势限价单在通道后期能赚钱——通道减弱，区间惯性开始取代趋势惯性
- [[trading-range-quality]]：区间质量判断（≥8K + ≥2测）是对 80% 法则的量化落地

## 实战应用
1. 先判断趋势还是区间
2. 趋势中：只看顺势信号，忽略所有逆势信号（无论看起来多漂亮）
3. 区间中：边界处逆势入场（低买高卖），不追突破
4. 例外处理：只有当看到强势反转棒 + 跟进确认时，才考虑"这可能是 20% 的成功"

### 80/20 法则的具体场景（来自 [[brooks-probability-table]]）

| 场景 | 80% 侧（大概率） | 20% 侧（小概率） |
|------|-----------------|-----------------|
| 趋势中反转/TR中突破 | 反转失败 / 突破失败 | 反转成功 / 突破成功 |
| 大幅低开首两小时 | 85% 回调 | 15% 不回调 |
| EMA下40+K后回调至EMA | 80% 测试低点下行 | 20% 远低于旧低点 |
| 上升通道上方突破 | 75% 5K内失败 | 25% 成功突破 |
| 昨日高潮 → 今日 | 75% 几小时TR | 25% 其他 |
| 多头突破后回调 | 90% 回调→通道/TR | 10% 反转 |
| 趋势日触及EMA | 99.5% 到达EMA | 0.5% 不到达 |

## 矛盾与待验证
- "80%" 是 Brooks 的经验估计还是可量化统计？不同品种和时间框架是否有差异？
- 趋势反转的 20% 成功率是否有更精确的信号组合可以提高？WG V1.5 的 RS 评分系统可能是对此问题的量化尝试
- 80% 法则与  的关系：MTR 是否就是那 20% 的成功反转？
- 概率表中「99.5%」级别的精度需要质疑——这是统计还是直觉？
