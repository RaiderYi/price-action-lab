# 反转测试

## 一句话定义
反转后的第一次回撤——验证反转是否真实的决定性测试。

## 核心要点
- 每次反转必然伴随一次测试——价格回撤到新趋势的起点附近
- **测试成功** = 回撤不破反转起点，反转被确认
- **测试失败** = 回撤突破反转起点，反转是陷阱，原趋势恢复
- 测试是反转交易的关键入场时机——等待测试成功后再入场，而非反转瞬间

## 与相关概念的关系
- [[major-trend-reversal|Major Trend Reversal]]：MTR 发生后必须先通过反转测试才算确认
- [[final-flag]]：最终旗形突破（反转）后的旗形回撤 = 反转测试
- [[h2-l2-state-machine|H2/L2 State Machine]]：反转后的 H2/L2 入场本质上就是反转测试入场
- [[failed-reversal-continuation]]：反转测试失败 = 反转失败 = 原趋势延续的强信号
- [[reversal-day]]：反转日之后的次日开盘回撤 = 日线级反转测试

## 实战应用
反转K线出现后不要立即入场——等价格回撤到该反转棒50%-61.8%附近，观察是否形成更高的低点（多头反转）或更低的高点（空头反转），确认后再入场。如果回撤直接击穿反转起点，反转作废，转而考虑顺势入场。
