# 买压和卖压

## 一句话定义
买压和卖压是多空力量在棒线上的足迹——通过棒线数量、实体大小、收盘位置、影线方向和缺口来判断哪一方在控制市场。

## 核心要点

### 买压（Buying Pressure）的迹象
1. 多头棒多于空头棒
2. 连续的多头棒
3. 多头实体比空头实体大
4. 棒线收盘于高位（至少在中点之上）
5. 多头微型通道（没有回调）
6. 棒线有下影线（多头在低价买入）
7. 带有缺口的多头突破 + 跟进
8. 连续多头棒越来越多、多头实体越来越大
9. 连续空头棒越来越少、空头实体越来越小

### 卖压（Selling Pressure）的迹象
1. 空头棒多于多头棒
2. 连续的空头棒
3. 空头实体比多头实体大
4. 棒线收盘于低位（至少在中点之下）
5. 空头微型通道（没有回调）
6. 棒线有上影线（空头在高价卖出）
7. 带有缺口的空头突破 + 跟进
8. 连续空头棒越来越多、空头实体越来越大

### 「谁拥有这一棒？谁拥有这个市场？」
- 多头棒 → 属于多头
- 空头棒 → 属于空头
- 趋势中一方明显主导 → 价格朝主导方方向移动

### 交易区间中的买卖压
- 买卖压帮助预测突破方向
- 买压 > 卖压 → 预期多头突破，总在场内多头
- 卖压 > 买压 → 预期空头突破，总在场内空头
- 持续评估：连续多头棒出现、实体变大、缺口 → 多头突破概率上升

### 通道中买卖压的变化
- **多头通道卖压增加**：回撤和 TTR 出现 → 通道可能演变为交易区间
- **空头通道买压增加**：连续多头棒、下影线 → 通道可能演变为交易区间
- 通道中 75% 的概率朝趋势相反方向突破（通道通常演变为交易区间）

## 实战应用
快速扫描最近 10-20 棒：(1) 多空棒数对比？(2) 实体大小对比？(3) 收盘位置？(4) 有没有缺口？四个维度的答案指向同一个方向 → 顺势交易；指向矛盾 → 可能进入区间。
