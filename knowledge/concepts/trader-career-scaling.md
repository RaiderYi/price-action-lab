# 交易生涯进阶之路

## 核心定义
交易生涯进阶之路是Al Brooks提出的交易者成长路径：从小处着手逐步扩大规模，以"不在乎仓位"的状态进行学习，每天专注于1-2个高质量交易机会。

## 详细说明

### 从小处着手，逐步扩大

**初始策略：**
- 新手应非常谨慎，每天只专注于一到两个最高质量的波段交易机会
- 例如趋势中的回调买入或反弹卖出

**盈利核心：**
- 实现可观收入的关键**不在于单次巨大盈利**，而在于稳定地获取小额利润
- 随着能力的提升逐步增加仓位

**实例：** 在标普股指期货（ES）中，每天稳定赚取1个点，当仓位扩大到10手时，年收入可达10万美元。

**交易本质：** 价格行为是机构行为的"足迹"，交易的目标是以机构的思路进行思考和操作。

### "不在乎仓位"原则

**概念**：仓位要小到即使亏损也完全不会影响情绪，从而能够客观地学习市场。这是克服交易恐惧的最有效方法。

**应用：**
- 初学阶段采用极小的仓位
- 专注于学习市场规律，而非盈亏结果
- 只有在稳定盈利后才逐步扩大规模

### 正确的进阶路径

1. **起步**：极小额仓位，每天1-2个高质量交易
2. **稳定**：在小仓位下持续盈利
3. **扩大**：逐步增加仓位，而非增加交易频率
4. **专业**：达到"不在乎"的仓位规模，像机构一样思考
