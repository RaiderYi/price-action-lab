# 突破模式

## 一句话定义
市场处于一个两个方向都可能突破且将有跟进的状态 — 三角形/楔形收敛到末端、通道加速、或横盘后即将爆发，方向不确定但突破迫在眉睫。

## 核心要点

### 什么是突破模式
- Brooks 定义：*"A setup where a breakout in either direction should have follow-through."*
- 与的区别：区间中的突破 80% 会失败，而突破模式中**突破即将成功**
- 突破模式是区间的终极收敛阶段 — 多空双方都已加仓到极限

### 突破模式的可识别形态
1. **三角形收敛**（Contracting Triangle）：更高低点 + 更低高点 → 即将突破
2. **上升三角形**（Ascending Triangle）：水平阻力 + 上升趋势线 → 偏多突破
3. **下降三角形**（Descending Triangle）：水平支撑 + 下降趋势线 → 偏空突破
4. **紧密 TR 末期**：棒线范围逐渐收窄 → 爆发
5. **通道加速失败**：陡峭通道突破上轨失败反转回通道 → 往往打穿下轨

### 交易突破模式
- 不要预测方向 — 等待突破发生后判断
- 强力突破（大实体趋势棒 + 跟进）→ 追趋势或等回调入场
- 弱势突破（小实体/长影线/无跟进）→ 可能是假突破 → 等失败后反向入场
- 突破后的测量运动目标 ≈ 突破前通道/区间的**高度**

### 三角形 = 突破模式
- 三角形 = 有三推的交易区间，已进入突破模式
- 如果超过 5 推，不再叫三角形，回到普通区间
- 三角形中的突破方向微弱偏向于前置趋势方向

## 与相关概念的关系

## 实战应用
当图表上的三角形/楔形收敛到快接近顶点时，设置双向预警。等突破棒收盘后评估：实体大 + 影线小 + 有跟进 → 顺势入场；实体小 + 影线大 + 无跟进 → 可能是假突破；如果突破后立即反转回通道内 → 通常打穿另一边 → 做反向突破。

## 矛盾与待验证
- Brooks 说三角形突破方向「微弱偏向前置趋势」，但未量化「微弱」是多少（55%？60%？）
- 突破模式与普通区间的边界在哪里？「即将突破」是可预测的还是事后才能确认？
