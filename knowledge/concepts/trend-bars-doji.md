# 趋势棒与十字星

## 一句话定义
所有蜡烛只分为两种类型——趋势棒（低周期趋势）和十字星/区间棒（低周期交易区间），这是 Brooks 读图的最基本单元。

## 核心要点
- **趋势棒**：小影线、大实体，代表低周期上的趋势
  - 多头趋势棒 = 白色/绿色实体，收盘近高点
  - 空头趋势棒 = 黑色/红色实体，收盘近低点
  - 实体 ≥ 棒高一半 → 倾向于视为趋势棒
- **十字星 (Doji)**：突出影线、小实体，代表低周期上的交易区间
  - 完美的十字星收盘等于开盘（无实体）
  - 实体 < 棒高一半，尤其是实体不大时 → 倾向于视为十字星
  - 单棒交易区间 = One bar Trading Range
- 有影线的趋势棒 = 弱趋势棒（带有交易区间属性）

## 与相关概念的关系
- [[market-structure]]：趋势棒序列 = 趋势市场；十字星序列 = 交易区间
- [[bar-close-position]]：趋势棒的收盘位置是关键过滤条件
- [[abc-pullback]]：H2/L2 的信号棒必须是趋势棒

## 实战应用
快速扫图时先看实体大小和影线——连续大实体小影线 = 强趋势，可以顺势追；长影线开始出现 = 趋势减弱，准备进入区间模式。
