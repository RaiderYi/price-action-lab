    10|# 双顶双底 (Double Tops & Bottoms)
    11|
    12|## 一句话定义
    13|双顶和双底是最常见的价格形态，既可以是延续形态（旗形），也可以是反转形态，每个MTR本质上都是某种双顶或双底。
    14|
    15|## 核心要点
    16|
    17|### 双重身份
    18|- **反转形态**：多头趋势中的双顶 → 可能反转为空头；空头趋势中的双底 → 可能反转为多头
    19|- **旗形（延续）形态**：
    20|  - 空头趋势中的双顶 = 双顶空头旗
    21|  - 多头趋势中的双底 = 双底多头旗
    22|- 背景决定身份：多头趋势 → 双底 = 牛旗；空头趋势 → 双顶 = 熊旗
    23|
    24|### 为什么双顶双底有效？
    25|- 市场总是在寻求确认——从一个价格反转后，市场想要确认它是强支撑/阻力
    26|- 第二次测试同一价位 → 空头/多头再次尝试但失败 → 对手方控制
    27|- 高位2牛旗有效：空头第一次反转失败后持有，第二次反转再失败 → 空头放弃
    28|
    29|### 核心规则
    30|1. **每个MTR顶部都是双顶的变体**，每个MTR底部都是双底的变体
    31|2. **双顶双底很少完美** — 电脑只是寻找前高前低的测试，不完美没关系
    32|3. **微型双顶** → 大反转概率小，但如果是更大双顶的一部分 → 增加概率
    33|4. **跌破颈线 + 更低低点** → 多头趋势结束
    34|5. **反弹超过双顶颈线** → 向上的测量移动
    35|
    36|### 双顶双底的测量移动
    37|- 无论成功还是失败，往往导致测量移动
    38|- 跌破颈线 → 向下投影（颈线到顶部的距离）
    39|- 每个空头突破 = 未形成底部的双底 → 下跌为测量移动
    40|
    41|### 失败的双顶双底 = 楔形变体
    42|- 双底向下突破后反转上涨 = 楔形底
    43|- 双顶向上突破后反转下跌 = 楔形顶
    44|- 失败的双顶/双底是楔形的一种特殊形式
    45|
    46|### 三重顶/底
    47|- 完美的三重顶/底比双顶/底更罕见
    48|- 三重底经常是复杂的双底
    49|- 接近就足够了
    50|
    51|## 与相关概念的关系
    52|- [[major-trend-reversal|Major Trend Reversal]]：所有MTR都是更高时间框架的双顶/双底
    53|- [[three-push-wedge|Three Push Wedge]]：失败的双顶/双底是楔形的变体
    54|- [[final-flag]]：趋势后期TTR中的双顶 → 可能最终旗形
    55|- [[support-resistance|Support/Resistance]]：双顶双底是S/R测试的核心机制
    56|- [[trend-inertia]]：趋势惯性解释为何大多数双重顶/底不反转
    57|- [[second-entry-reversal]]：双顶/底常提供二次入场机会
    58|
    59|## 实战应用
    60|看到任何小幅反转时，先将其视为旗形/TR，而非大反转。只有当双顶/双底出现在更大形态的背景下，且有强信号棒确认时，才按MTR交易。
    61|

    67|## 矛盾与待验证
    68|- Brooks 反转篇明确指出：多头趋势中的双重顶 80% 向上突破而非向下反转——"没有可靠的反转形态，只有失败的延续形态"。传统教材将双重顶视为反转形态的说法需要在此框架下重新理解。见 [[trend-inertia]]。
    69|- 双重顶/底在 A 股中的可靠性需要进一步统计验证

    71|### 书-码差异（来源：[[article-huangzongprice-pa-shape-audit]]）
    72|**bear_double_top（双顶空头旗形，major_diff，28 samples）**：
    73|- 趋势前提：书本 `bear_trend_or_TR_high` → 代码 `bear_or_TR_high`（省略了趋势强制要求）
    74|- 腿计数：书本「双顶本质是 L2」→ 代码「两个价位接近的局部高点，价差≤0.5 ATR」
    75|- 价位关系：书本用颈线测量目标 → 代码额外约束「双顶整体不高于 EMA20+3ATR」
    76|
    77|**bull_double_bottom（双底多头旗形，major_diff，8 samples）**：
    78|- 趋势前提：书本 `bull_trend_or_TR_low` → 代码 `bull_or_TR_low`
    79|- 腿计数：书本「双底本质是 H2」→ 代码「两个价位接近的局部低点，价差≤0.5 ATR」
    80|- 价位关系：代码额外约束「双底整体不深于 EMA20-3ATR」
    81|
    82|**关键问题**：书本将双顶/双底视为 L2/H2 的等价物，但代码将其作为独立形态检测——两种实现路径的识别结果可能不一致
    83|- **书本 vs 实现差异（major_diff）**： 发现 bear_double_top 和 bull_double_bottom 的 5/5 维度均与 Brooks 原著不一致——趋势前提简化为 bear_or_TR_high/bull_or_TR_low、腿计数改为 15 根内双高点/低点且价差 ≤0.5 ATR、颈线计算规则与 Brooks 描述不同。Brooks 说"任何双顶本质上都是 L2 卖点"，实现也设置了 rs≈68 几乎等同 L2 变体，但在趋势前提和颈线规则上与原著有显著偏差。
