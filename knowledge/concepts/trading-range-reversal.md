# 区间内反转 (Trading Range Reversal)

## 一句话定义
在明确或即将形成的交易区间内，利用动能在支撑/阻力边界的假突破和过冲，在边界附近做反向入场。

## 核心要点

### 区间反转的本质
- 区间行情明确之前，市场就已经在走出区间的价格行为
- 区间的典型特征：快速强动能冲向边界 → 制造突破假象 → 在边界附近获利盘涌现 → 飞速反转
- 区间反转 = 假突破 + 获利了结 + 反向建仓的三合一行为

### 假突破与过冲机制
- 动能方往往会**过冲**支撑/阻力位，出现买盘或卖盘真空
- 真空出现后动能方迅速获利离场（买盘真空=多方跑光，卖盘真空=空方跑光）
- 反转方暂时避让动能方——等过冲后拿到**更好的进场价**（低于前低一点买入，高于前高一点卖出）
- 结果：做突破的套牢，做反转的拿到更优价

### 区间反转的实战信号
| 信号 | 解读 |
|------|------|
| BTC 趋势后出现深度回撤 | 今天可能是区间日 |
| 棒线有明显引线、重合严重 | 多空双方都对跟随盘失望 |
| 深度而频繁的反抽/回撤 | 趋势难持续 → 区间行为 |
| 几乎没有连续 2-3 根收线好的趋势棒 | 无跟随动能 |
| 昨天是盘整日 | 今天大概率也是区间 |
| 困惑感、trail 总是被打掉 | 有经验的交易者会相信直觉 → 改用限价单做反转 |

### 入场规则
1. **等待二次入场机会**：区间动能腿往往看起来特别强，不要在第一波就反手
2. **区间上部 1/3 做空**：以早盘区间顶部为参照，寻找二次入场点（往往是小双顶形式）
3. **区间下部 1/3 做多**：在区间底部附近寻找二次入场点（往往是小双底形式）
4. **半仓操作**：交易区间内没有高概率交易，控制仓位

### 有经验者 vs 初学者
- **有经验的交易者**：感到困惑 → 相信直觉 → 切换为限价单刮头皮（Trading Range 模式）
- **初学者**：困惑 → 生气 → 「市场在愚弄我」→ 对着干 → 赔一天

## 与相关概念的关系
- [[trading-range-quality]]：区间反转的前提是有质量的区间（≥8K + ≥2测），但本概念更强调在区间确立之前的早期识别
- [[eighty-percent-rule]]：区间中 80% 突破失败 → 区间反转正是利用这个规律
- [[breakout-mechanics]]：区间反转是做假突破的反面——做突破的人止损，做反转的人盈利
- [[momentum-vs-value-traders]]：区间反转本质是价值交易者（等边界）的操作，动量交易者容易在边界被套
- [[support-resistance|Support/Resistance]]：区间反转的入场位在支撑/阻力边界的过冲处

## 实战应用
早盘出现 BTC 趋势后深度回撤 → 警觉可能是区间日 → 标记早盘高低点区间 → 等区间上部 1/3 二次入场做空，或下部 1/3 二次入场做多 → 不追突破，只等反转。

## 矛盾与待验证
- 区分「区间日」和「趋势日中继盘整」是实盘最难的点——两者早期特征几乎相同
- Brooks 说「有经验的交易者会依赖直觉」——这是不可量化的主观判断，在量化系统中如何替代？
