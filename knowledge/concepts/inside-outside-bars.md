# 内包棒、外包棒和突破模式

## 一句话定义
内包棒（ib）和外包棒（ob）是双棒反转的特殊形态；ii/iii/ioi/oio 是窄幅交易区间内的突破模式（BOM），在良好背景下可作入场架构。

## 核心要点

### 内包棒（ib — inside bar）
- 当前棒的高点 ≤ 前一棒高点，且低点 ≥ 前一棒低点
- 是双棒反转的一种类型
- 作为买入信号棒需要好的背景：强突破后回撤、保持在前低之上、形成更高低点双底
- ib 之后几棒如果是强多头趋势棒（大实体收高位），则为有效信号

### 外包棒（ob — outside bar）
- 当前棒的高点 ≥ 前一棒高点，且低点 ≤ 前一棒低点
- 可以是突破和入场棒；如果前一棒是信号棒，盈利概率更高
- **第一个小时的大外包棒常启动波段交易**
- **外包棒经常是个陷阱**：棒大、止损远、风险大；背景不好时，上方更有可能是卖家

#### 外包棒的应对
- **TTR 或上升趋势中**：在空头外包棒下方买入
- **TTR 或下降趋势中**：在多头外包棒上方卖出
- **趋势中**：多头趋势中在多头外包棒上方买入；空头趋势中在空头外包棒下方卖出

### ii 形态和突破模式（BOM）
- **ii** = 连续两根内包棒
- **iii** = 连续三根内包棒
- **ioi** = 外包棒后的内包棒
- **oio** = 内包后的外包再内包
- 这些都是窄交易区间（TTR）内的突破模式，**背景是关键**
- TTR 超过 10-20 棒 → 突破概率低，等待突破而非入场
- ii 在低周期上通常是三角形

### ii 作为最终旗形
- ii 代表多头和空头的平衡，可能是最后的多头/空头旗
- 如果突破失败 → 可能导致趋势反转而不仅是横盘
- 「买入收盘」的多头看到 ii 空头棒会失望 → 试图盈亏平衡出场 → 被套 → 加剧下跌

### 趋势中的 ioi
- **ioi 在多头趋势中** → 可能是多头旗（高点 2）
- **ioi 在空头趋势中** → 可能是空头旗（低点 2）
- 回调到均线 + ioi = 高概率旗形
- 如果 ioi 的第三棒是阳线收高位 → 很好的买入架构

## 实战应用
看到 ii/ioi 时先看背景——是 20 棒以上的大 TTR 里（无意义），还是趋势回调 3-5 棒（高概率旗形）？不在大 TTR 中追突破，不在无背景处接 ib/ob。

### 概率数据（来自 [[brooks-probability-table]]）

| 场景 | 概率 |
|------|------|
| 外包下行日（Outside Down Day）收于区间下 1/3 | **70%** |
| 外包下行日收于中点以上 | **仅 20%** |

这对外包下行日提供了重要的方向偏斜——如果出现外包下行日且当前在区间上沿附近，70% 的概率该日收于下 1/3，这意味着做空有统计优势。

## 矛盾与待验证
- Brooks 说外包棒在 TTR 中最好用限价单反向操作，但这与趋势中顺势追 ob 矛盾——关键在于准确判断当前处于趋势还是 TTR
