# Brooks 概率表

## 一句话定义

Al Brooks 价格行为学中所有量化概率规则的汇编——从 90% 到 10% 逐级降序，为交易决策提供概率数学基准。

## 核心要点

- **框架定位**：Brooks 原著中散布的概率规则被 huangzongprice 系统整理为 9 档概率层级（90%→10%），覆盖约 40+ 条规则
- **与 [[forty-sixty-rule]] 的关系**：40-60 规则是理论基础（90% 时间概率在 40%-60%），概率表是具体场景的实践数据点
- **与 [[trader-equation]] 的关系**：概率表中的数值可直接代入交易者方程式——胜率×回报 > 失败率×风险——计算盈亏平衡条件
- **最重要的元发现**：90% K 线在 TR 中——趋势是稀有事件，这解释了为什么  是 Brooks 系统核心

## 概率层级完整表

### 90% 层级（近乎确定）

| # | 规则 | 含义 |
|---|------|------|
| 1 | 图表上 90% K 线处于交易区间 | 趋势是稀有状态，TR 是常态 |
| 2 | 强多头趋势日（>50K 高于 MA），99.5% 至少 3 根 K 低点低于 EMA | 再强的趋势也有回撤 |
| 3 | 无论趋势多强，99.5% 的日子到达 EMA | 趋势日内必碰 EMA——核心回撤规律 |
| 4 | 突破阶段→90% 回调→通道/TR，仅 10% 反转 | 突破后回调是预期行为 |
| 5 | 每天 90% 概率至少一次波段机会：好信号棒、≥40% 日均波幅、≥2 腿、RR≥2:1、持续 1-2h | 每天有值得交易的架构 |

### 80%/85%/75% 层级（高概率）

| 概率 | 规则 |
|------|------|
| 80% | **趋势中反转尝试失败**（核心 80/20 法则） |
| 80% | **TR 中突破尝试失败**（核心 80/20 法则） |
| 85% | 大幅低开，首两小时内回调 |
| 80% | EMA 下方运行 40+K 后回调至 EMA → 测试低点下行 |
| 75% | 昨日高潮 → 今日几小时 TR |
| 75% | 大幅低开 → 趋势型 TR 日 |
| 75% | 上升通道上方的突破 5K 内失败 |

### 70%/75% 层级（可靠优势）

| 概率 | 规则 |
|------|------|
| 70% | 惊喜 K 线（异常大）→ 等距运行（特别是好 FT 时） |
| 70% | 2+ 连续大阳棒收高位、几乎无重叠 → 至少等距上行 |
| 70% | 头皮交易胜率（但需回报≥风险才值得做） |
| 70% | 多头试图突破三角形上方 → 回调至三角形顶点 |
| 70% | 外包下行日收于区间下 1/3（仅 20% 收于中点以上） |
| 70% | 大幅低开 → 上午 10 点后下行 |

### 60% 层级（需要 RR≥1:1 才能盈利）

**趋势中的回调入场（6 种 "always-in" 架构）**：

| # | 架构 | 方向 |
|---|------|------|
| 1 | 多头趋势中回调至 MA 的 High 2 买入 | 多 |
| 2 | 空头趋势中回调至 MA 的 Low 2 卖出 | 空 |
| 3 | 多头趋势中楔形牛旗回调买入 | 多 |
| 4 | 空头趋势中楔形熊旗回调卖出 | 空 |
| 5 | 多头趋势中突破牛旗后的突破回调买入 | 多 |
| 6 | 空头趋势中突破熊旗后的突破回调卖出 | 空 |
| 7 | 强多头急速后的 High 1 回调买入（非买入高潮后） | 多 |
| 8 | 强空头急速后的 Low 1 回调卖出（非卖出高潮后） | 空 |

**区间中的逆势入场**：

| # | 架构 |
|---|------|
| 9 | TR 顶部卖出（特别是二次入场） |
| 10 | TR 底部买入（特别是二次入场） |

**趋势反转（60% 或更高）**：

| # | 架构 |
|---|------|
| 11 | 强力突破趋势线→测试极值→好反转信号棒→反转 |
| 12 | 强劲末端旗形反转 |
| 13 | 下降阶梯第三次/第四次下行买入 |
| 14 | 上升阶梯第三次/第四次上行卖出 |

**限价单入场（需丰富经验）**：

| # | 架构 |
|---|------|
| 15 | 强多头突破后急速→市场/收盘/前低挂限价单买入 |
| 16 | 强空头突破后急速→市场/收盘/前高挂限价单卖出 |
| 17 | 空头突破至等距目标位→限价单买入（非太强突破） |
| 18 | 多头突破至等距目标位→限价单卖出（非太强突破） |
| 19 | 强反转后可能的新趋势/TR 底部→低 1/2 弱信号棒下方限价单买入 |
| 20 | MA 处平缓牛旗→前低/下方限价单买入 |
| 21 | 向上突破牛旗→K 线下方买入（预期突破回调） |

**其他 60% 规则**：

| 规则 |
|------|
| 开盘 15-20K 卖出高潮→60% 演变成 TR |
| 60% 趋势型 TR 反转测试前一个 TR |

### 50% 层级（抛硬币——需更大回报）

| 规则 |
|------|
| 50% 开盘强劲运动反转 |
| FOMC 突破 50% 反转（同开盘突破） |
| 昨日买入高潮→50% 次日首小时跟进买入（反之亦然） |
| 空头趋势后期 2 根大 K→50% 结束 + 50% 再一条小腿 |
| 突破模式（BOM）→50% 成功突破 + 50% 首次突破失败 |

### 40% 层级

| 规则 |
|------|
| MTR 架构 40% 概率产生波段利润 |
| 大幅低开首 K 收高位（BLBCOH after BGD）→40% 成为当日最低价 |

### 30%/35% 层级

| 规则 |
|------|
| MTR 架构 30% 小额亏损 + 30% 小额盈利 |
| 多头惊喜棒仅 30% 引发空头趋势（反之亦然） |
| 大幅低开→仅 35% 当日回补缺口 |

### 20%/25% 层级

| 规则 |
|------|
| **趋势中 20% 反转成功**（80/20 法则成功侧） |
| **TR 中 20% 突破成功**（80/20 法则成功侧） |
| 仅 20% 首 K 高/低点成为当日极值 |
| 买入高潮日后 25% 次日上行 1-2h |
| 空头趋势后期 2 根大空头 K→仅 20% 成为测量缺口 |

### 10% 层级

| 规则 |
|------|
| 仅 10% 时间市场处于突破模式（价格快速寻找新 TR） |
| 多头突破后反转仅 10%（通常为抛物线楔形顶） |

## 实战应用

**概率思维做决策**：不在胜率 50% 的架构中冒等量风险——需要更大回报来补偿。60% 架构配合 RR≥1:1 即可盈利，但 40% 的 MTR 需要 RR≥1.5:1。所有概率数据应代入  计算期望值。

## 与相关概念的关系

- [[forty-sixty-rule]]：概率表的数学基础——Brooks 认为 90% 时间概率在 40%-60% 区间。概率表中的 60% 和 40% 层级正好在这个「灰色地带」两端。
- [[eighty-percent-rule]]：概率表的核心条目——趋势反转失败 80%、TR 突破失败 80%。本表补充了该法则在 7 个场景中的具体表现。
- [[trader-equation]]：概率表提供胜率输入，方程式计算盈亏平衡条件
- [[swing-vs-scalp]]：90% 每天有一次波段机会——论证波段交易优于头皮交易
- [[gap-probability-chain]]：大幅低开场景的专项概率链（从本表提取的独立概念）

## 矛盾与待验证

- **跨市场适用性**：所有概率数据来自 Brooks 对美股指数期货（ES）的观察（~2010s），在 A 股和 BTC 市场的实际概率可能有偏差。建议通过回测验证关键概率（如 80/20 法则、60%入场架构）在目标市场的实际表现。
- **时间衰减**：部分概率（如 FOMC 突破）对应特定市场微观结构时期，当前市场结构变化后这些概率可能已漂移。
- **高概率层级的精度疑问**：「99.5%」级别的概率难以在有限样本中验证——可能更接近 Brooks 的经验直觉而非严格统计。
