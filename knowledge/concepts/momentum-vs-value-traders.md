# 动量交易者 vs 价值交易者

## 一句话定义
两种永远共存的交易风格——动量交易者追突破（高概率+高风险），价值交易者等回调（低风险+较低概率），一方赚钱必须以另一方站在对立面为代价。

## 核心要点

### 对比表
| 维度 | 动量交易者 (Momentum) | 价值交易者 (Value) |
|------|---------------------|-------------------|
| 入场方式 | 突破时直接入场 | 等回调后再入场 |
| 多头方向 | 高位买入，预期更高 | 回调买入，降低风险 |
| 空头方向 | 低位卖出，预期更低 | 反弹卖出，降低风险 |
| 概率 | 高（顺势突破通常延续） | 较低（回调不一定恢复） |
| 风险 | 大（止损在突破起点下方/上方） | 小（止损紧贴回调极值） |
| 回报 | 波段利润 | 通常较小（回调后的反弹空间有限） |
| 适用阶段 | 突破阶段、窄通道 | 宽通道、趋势中的回调 |
| 止损位置 | 远离入场点（突破起点之外） | 紧贴入场点（更高低点下方） |

### 核心洞察
- **概率与风险永远负相关**：高概率交易 = 高风险（因为止损远），低风险交易 = 较低概率（因为回调后趋势可能不恢复）
- **两者永远共存**：你的买入需要有人卖出——如果你是动量买入者，对手方可能是价值卖出者（认为价格过高）
- **这解释了市场周期的必然性**：动量交易者驱动突破，但当足够多的价值交易者开始逆势获利时，通道减弱，市场进入交易区间

## 与相关概念的关系
- [[fsm-market-cycle]]：动量交易者在突破和窄通道中占优，价值交易者在宽通道和交易区间中占优
- [[breakout-mechanics]]：动量交易者是突破阶段的主要参与者
- [[abc-pullback]]：价值交易者等待的回调入场结构（H2/L2）
- [[channel-to-trading-range]]：价值交易者（限价单 + 止损单逆势）开始赚钱是通道→区间过渡的信号
- [[eighty-percent-rule]]：动量交易者押注 80% 的趋势惯性；价值交易者押注"趋势终究会减弱"

## 实战应用
1. 先判断市场周期位置
2. 突破/窄通道阶段 → 做动量交易者：顺势入场，接受远止损，目标波段利润
3. 宽通道/交易区间阶段 → 做价值交易者：等回调入场，紧止损，目标刮头皮
4. 不要在突破阶段做价值交易（趋势太强，回调不出现或太浅）
5. 不要在宽通道晚期做动量交易（通道减弱，追突破被套概率高）
