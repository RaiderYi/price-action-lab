# 买入真空与卖出真空（Buy Vacuum / Sell Vacuum）

## 一句话定义
支撑/阻力像磁铁一样吸引价格快速逼近，到达后磁力消失——逼近过程是「真空」，到达后通常反转。

## 核心要点
- **买入真空（Buy Vacuum）**：价格被磁吸式拉升至阻力位的过程——空头停止卖出（等待更高价），多头激进买入，形成大阳线急速拉升
- **卖出真空（Sell Vacuum）**：价格被磁吸式打压至支撑位的过程——多头停止买入（等待更低价），空头激进卖出，形成大阴线急速下跌
- **到达后**：磁力大幅减弱或完全消失 → 多头在阻力位止盈 + 空头入场 → 反转
- **机制解释**：
  - 空头知道价格会到阻力位 → 停止卖出等到更高价
  - 相对缺乏卖盘 + 多头（含 HFT）激进买入 → 加速拉升
  - 到达阻力后双方预期兑现 → 多止盈 + 空入场 → 反转
- **真空棒特征**：通常是大实体趋势棒，收盘在极端位置，给人「要突破了」的错觉
- **与新手的陷阱**：新手看到大阳线逼近阻力就追多 → 正好买在空头入场的位置

## 与相关概念的关系
- [[support-resistance|Support/Resistance]]：真空效应是 S/R 发挥作用的核心机制
- [[trading-range-quality]]：交易区间的顶部=买入真空测试阻力，底部=卖出真空测试支撑；80% 突破失败
- [[eighty-percent-rule]]：区间中 80% 突破失败 = 真空到达后反转是常态
- [[fsm-market-cycle]]：真空效应解释了市场如何在区间→突破→新区间之间循环

## 实战应用
看到价格加速冲向 S/R 时，不要追——等到达后的反转信号（如双顶/双底、弱架构），做反向交易。区间策略 BLSHS 的逻辑基础即在于此。

## 矛盾与待验证
- 强突破中真空不会导致反转——需要区分「区间内的真空测试」和「趋势中的真实突破」。关键是真空到达后的前几根 K 线的买卖压力判断。
- 量化「磁力消失」的客观标准尚未定义——可能的代理变量：到达 S/R 后 N 根 K 线内出现反向架构。
