# 每一个跳动点都很重要 (Every Tick Matters)

## 一句话定义
市场中不存在"噪音"——每一个tick都是由算法精确计算并执行的，最小波动也可能触发大行情。

## 核心要点

### 市场由算法精确控制
- 市场由**数百台永不休息的计算机**控制
- 它们不断计算数字并执行交易
- 所有算法都清楚关键价格（支撑和阻力位）
- 因此价格波动**非常精确**——通常在预测的1个tick内结束

### 不存在"噪音"
- 初学者常将某些波动称为"噪音"——认为市场行为是随机的
- 实际上，这些波动是数百台计算机精确计算的结果
- 交易者**从不忽略任何波动**——每一个tick都是价格行为的实例

### 微小细节 → 大行情
- Brooks 实战案例：窄幅TR中形成的微型双顶（仅低于当日高点一个tick）
- 警觉交易者在信号棒下方一个tick做空 → 冒5个tick的风险
- 随后市场形成大阴线趋势棒——所有人一致认为空头获胜
- 紧止损 + 低风险 + 低概率 + 巨大回报 → 交易者方程式有利

### S/R 磁铁效应
- 关键价格（S/R位）像**磁铁**一样吸引市场
- 市场到达一个磁铁位后 → 决定下一个测试哪个磁铁
- 移动方向可上可下——关键是到达磁铁后的行为
- 所有算法都知道这些点位 → S/R精度极高

### 为什么每个tick重要
- 计算机程序在极短时间内同时做出相同决策 → 价格精确移动
- 看似微小的K线形态（如微型双顶）可能正是更大形态的触发点
- 忽略"小东西" = 错过关键信号
- 成功的交易者培养出识别这些微小但重要的细节的能力

## 与相关概念的关系
- [[price-action]]：此概念是PA定义的自然推论——如果PA是"任何价格变动表示"，那么每个tick都是该定义的一个实例
- [[support-resistance|Support/Resistance]]：S/R的磁铁效应——算法精确知道S/R位并据此交易，这是"每个tick都精确"的原因
- [[eighty-percent-rule]]：即使每个tick都重要，80%的反转尝试仍会失败——精确≠可预测
- [[markets-constantly-test]]：市场不断测试——每个tick都是对对手方承受能力的测试
- [[indicator-illusion]]：指标掩盖了每一个tick的细节——交易者失去了对微观市场结构的感知

## 实战应用
1. 不要将任何K线形态标记为"噪音"——每一根K线都在讲述市场故事
2. 关注窄幅TR中的微小形态变化（如微型双顶/双底）——它们可能是大行情的前兆
3. 理解S/R的磁铁效应后，在价格接近关键S/R时保持高度警觉
4. 小止损交易利用了这一原理——紧止损 + 巨大回报可以弥补低概率

## 矛盾与待验证
- "每个tick都重要"与 Brooks 在其他著作中讨论的"部分波动不值得交易"之间的关系——重要的≠值得交易的。每个tick都有信息价值，但并非每个tick都是入场机会
- 在 A 股 T+1 制度下，"小止损+大回报"的模式需要调整——无法当日止损后当日再入场
