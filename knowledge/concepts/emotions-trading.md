# 交易情绪与感受

## 一句话定义
Brooks 将交易心理重新框架化——恐惧与贪婪不存在于真实交易世界，真正重要的感受是"不确定""失望"和"紧迫感"，它们是判断市场状态的情感雷达。

## 核心要点
- **恐惧/贪婪** = 电影概念，现实交易中不存在（专业交易者从不考虑它们）
- 初学者恐惧的真相：怕赔钱（=死亡）、被看作赌徒、配偶的焦虑、害怕变得比自认为应得的更成功
- 真正影响交易的三种感受：
  - **不确定 (Uncertainty)** → 市场在交易区间 → 做 BLSHS（低买高卖刮头皮）
  - **失望 (Disappointment)** → 同样是交易区间信号 → 突破失败
  - **紧迫感 (Urgency)** → 强势移动/突破 → 必须立即入场，至少小仓位
- 如果你有任何情绪，你无法客观跟随机构 → 你会赔钱
- 解决办法：交易"我不在乎"的仓位规模（你认为合适的仓位 × 25%）

## 实战应用
交易中觉察自己的感受：如果你在等待回调但它一直不来、你感到焦虑 → 这是紧迫感 → 立即用小仓位入场。如果你对方向感到困惑、不确定 → 市场可能在区间 → 等待边界测试做反转。

## 矛盾与待验证
- Brooks 否定恐惧/贪婪在实际交易中的存在，但大量交易心理学文献以此为核心——这一立场是否过于绝对？
