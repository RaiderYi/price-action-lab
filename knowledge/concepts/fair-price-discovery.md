# 公平价格发现

## 一句话定义
市场存在的根本目的——聚集大量买卖双方，通过不断上下探测发现双方都认可的公平价格，从而实现最大化的交易量。

## 核心要点
- 市场如同一场拍卖，目的是找到买卖双方都认为公平的价格
- 公平价格不断变化（基本面不断变化）
- 市场通过上下探测来确认公平价格区间：
  - 太高 → 没有买家 → 必须下跌找买家
  - 太低 → 没有卖家 → 必须上涨找卖家
- 围绕公平价格形成交易区间 → 直到基本面变化 → 突破寻找新的公平价格
- 没有市场 = 挨家挨户推销，价格远离公平价；有市场 = 窄价差、即时交易
- **深层本质**：市场只是买卖的论坛——人类对买卖和定价的能力是经过数千年优化的生存技能，由基因控制。这意味着价格行为自市场出现以来从未改变（除非人类进化成新物种），计算机只是更快地做出相同逻辑决策

## 与相关概念的关系
- [[market-structure]]：公平价格区间 = 交易区间；寻找新公平价格 = 趋势
- [[support-resistance|Support/Resistance]]：支撑和阻力是公平价格区间的探测边界
- [[breakout-mechanics]]：基本面变化 → 公平价格变化 → 突破寻找新区间
- [[fair-price-discovery]]：市场向交易量最大化的方向移动（Brooks 对成交量的唯一认可维度）
- [[price-action]]：价格行为 = 公平价格发现过程的可视化记录 —— 买卖论坛中理性人类行为的外在表现

## 实战应用
理解市场在做什么：横盘 = 市场认可当前价格公平；突然的强突破 = 市场认为价格错了 → 跟随突破方向，因为市场正在寻找一个新的公平价格区间。
