# 波段交易 vs 刮头皮 (Swing vs Scalp)

## 一句话定义
波段交易追求回报≥2倍风险的中长线持仓，刮头皮追求极高概率的微薄利润；大多数交易者只应做波段交易。

## 核心要点

### 波段交易 vs 刮头皮对比

| 维度 | 波段交易 | 刮头皮 |
|------|---------|--------|
| **目标** | 回报 ≥ 风险2倍 | 微薄但高确定性的利润 |
| **概率** | 40-60% | 70-90% |
| **风险/回报** | 高回报，低概率 | 低回报，高概率 |
| **持仓时间** | 10-20+棒，最低TBTL | 1-5棒 |
| **止损** | 宽止损（波段止损） | 紧止损（但专业者用波段止损） |
| **适合人群** | 新手和大多数交易者 | 有经验的持续盈利交易者 |
| **TR环境** | 不利（大量反转和横盘） | 双向都可以 |
| **趋势环境** | 顺势持有 | 顺势刮头皮，回调反转时也刮 |

### 波段交易关键规则
1. **最低目标**：10棒 + 两条腿(TBTL)
2. **回报至少是风险的2倍**
3. **只允许一次突破入场测试**：如果价格第二次回到入场价 → 是TR而非趋势 → 退出
4. **在趋势方向上做波段**：强突破 → 至少部分仓位波段
5. **波段交易者**：小反转 = 可能回调/趋势恢复，大反转 = 可能趋势反转

### 刮头皮关键规则
1. **新手应避免刮头皮** — 新手忽略小风险=低概率，逆势=小回报
2. **顺势刮头皮更安全**，即使在弱趋势中
3. 刮头皮使用波段止损并扩大规模（专业者）
4. **切勿将刮头皮转为波段**（亏损加仓扩大损失）
5. 可将波段转为刮头皮（前提变化时）

### 交易者方程与策略选择
- 波段：40%胜率 × 2倍回报 > 60%败率 × 1倍风险 → 正期望值 ✅
- 刮头皮：80%胜率 × 0.5倍回报 > 20%败率 × 1倍风险 → 正期望值 ✅
- 两者数学上都合理，关键是管理得当

### 强突破时的刮头皮
- 顺势刮头皮概率高（60%+）
- 反复刮头皮并不容易 → 最好还是波段交易

## 实战应用
默认做波段交易（2倍风险回报）。只在强趋势中顺势方向做刮头皮。当市场进入TR → 切换为刮头皮模式，BLSHS。

### 概率基础（来自 [[brooks-probability-table]]）

| 数据 | 数值 | 含义 |
|------|------|------|
| 每日波段机会概率 | **90%** | 每天至少一次：好信号棒 + ≥40%日均波幅 + ≥2腿 + RR≥2:1 + 持续1-2h |
| 头皮交易胜率 | **70%** | 但需要回报≥风险才值得做 |
| 头皮交易警告 | **必须RR≥1:1** | 大多数交易者无法持续选到70%胜率的头皮，所以回报必须至少等于风险 |

核心推论：既然每天有 90% 概率出现波段机会，而头皮需要 RR≥1:1（本质等于小波段），那么对大多数交易者来说等待波段机会比频繁做头皮更优。
