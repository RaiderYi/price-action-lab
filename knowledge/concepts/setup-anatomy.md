# 架构剖析

## 一句话定义
架构（Setup）由两部分组成——信号棒和背景；两者都强才是高概率架构，任何一方弱都需要更多的确认信息。

## 核心要点

### 架构的两大组成部分
1. **信号棒**：提供具体的入场信号（反转、突破等）
2. **背景**：信号棒左边所有的棒——决定这个信号的可靠性

### 背景的评估维度
- **趋势方向**：顺势交易的信号棒可以弱一些；逆势交易必须有强信号棒
- **位置**：是否在支撑/阻力位？是否在交易区间顶部/底部？
- **交易区间中**：80% 的突破尝试会失败 → 在顶部买、底部卖是低概率
- **强趋势中**：不要逆势——即使有好的反向信号棒也不要交易

### 弱架构 → 需要更多信息
当信号棒和/或背景不够强时，三种策略：
1. **等待**：等更强的信号或更好的背景出现
2. **等待二次信号**：第一个信号不好 → 等第二个信号入场（概率更高）
3. **宽止损 + 加仓**：专业交易者的选择（风险更大）

### 强突破和跟进 → 以任何理由交易
- 强势多头突破 + 强跟进棒 → 「总在场内多头」（Always In Long）→ 以任何理由买入
- 强势空头突破 + 强跟进 → 「总在场内空头」（Always In Short）→ 以任何理由卖出
- 买入/卖出理由：市价、前棒上方/下方、多头/空头棒收盘、回调等

### 逆势交易 = 必须强信号棒
- 多头趋势中做空：信号棒不强不要卖
- 空头趋势中做多：信号棒不强不要买
- 强趋势中 80% 的反转尝试会失败

### 弱卖出架构的例子
- 卖出信号棒弱 + 做空背景弱（如 14 棒多头微型通道无回调）
- 对策：等待强势反转下跌后再卖，而非在第一个弱信号棒入场

## 实战应用
每看到一个信号棒，先问：(1) 左边是什么趋势/结构？(2) 位置好吗（支撑/阻力/区间中）？(3) 信号棒本身强吗？三个都 YES → 入场；两个以下 → 等待或等二次信号。
