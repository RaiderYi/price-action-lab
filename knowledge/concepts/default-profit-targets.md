# 默认利润目标

## 一句话定义
当你不确定在哪里获利了结时，使用数学上总是合理的默认计划：2倍初始风险减半 + 3倍再减25% + 剩余波段持有跟踪止损。

## 核心要点

### 默认计划（Reasonable Default）
```
在 2x 初始风险处：减持一半（50%）
在 3x 初始风险处：再减持 25%
剩余仓位：波段持有，跟踪保护性止损
交易时段结束前：退出
```

### 为什么这个计划数学上总是合理
- 如果概率 ≥ 40%（大多数交易的最低概率），回报 ≥ 2x 风险 → **交易者方程总是正的**
- 初始风险总是**大于**实际风险（因为实际风险 = 入场到被证明错误的价格距离，通常小于初始止损距离）
- 因此 2x 初始风险 = 至少 2x 实际风险 → 即使概率只有40%，期望值也为正

### 高概率 vs 低概率的不同目标

| 概率 | 最低利润目标 | 理想目标 | 原因 |
|------|------------|---------|------|
| 高概率（60%+） | 1x 实际风险 | ≥1x 初始风险 | 高概率补偿了较小的回报 |
| 低概率（40%） | 2x 实际风险 | ≥2x 初始风险 | 需要大回报来补偿低胜率 |
| 强突破后 | ≥2x 初始风险 或 测量移动 | 波段持有 | 趋势强劲，应该争取更多利润 |

### 实际风险 vs 初始风险
- **实际风险 (Actual Risk)**：入场价到合理止损位（回撤极点上方/下方）的距离
- **初始风险 (Initial Risk)**：信号棒上方/下方到入场价的距离（通常大于实际风险）
- 当实际风险非常小时（如利用低时间框架早期入场），使用初始风险来计算目标更合理

### 可以改变目标的时机
默认计划是**底线**（minimum），而非上限。可以基于以下因素调整：
- 支撑/阻力位
- 市场动量减弱
- 出现可信的相反信号棒
- 测量移动目标 (Measured Move)
- 交易时段快结束时

### 关键原则
- "以两倍实际风险获利总是好的，但很少是最优的"
- "刮头皮的数学很好，但如果你该做波段时刮头皮，最终会错过80%的趋势"
- "当你不确定时，2x初始风险减持一半"——这是一个永远不会让你后悔的默认值

## 实战应用
1. 每笔交易进场后立即设定默认获利计划：2x 初始风险处下限价单卖出50%
2. 如果市场走到2x → 自动成交一半，将剩余仓位的止损移至盈亏平衡
3. 在3x初始风险处设置第二个限价单卖出25%
4. 剩余25%跟踪止损——使用每个新高/新低后的主要回撤极点
5. 如果出现可信的相反信号棒→提前全部退出
