# 二元决策框架

## 一句话定义
面对任何图表，依次回答四个"非此即彼"的问题来确定市场状态——将复杂的价格行为简化为二元决策链。

## 核心要点

### 四个问题（按顺序）
```
问题 1：趋势还是交易区间？
  ├→ 趋势 → 问题 2
  └→ 交易区间 → 低买高卖刮头皮（不继续后续问题）

问题 2：突破还是通道？
  ├→ 突破 → 只做顺势方向（动量交易）
  └→ 通道 → 问题 3

问题 3：窄通道还是宽通道？
  ├→ 窄通道 → 只在趋势方向交易（顺势回调入场）
  └→ 宽通道 → 顺势为主，对手可刮头皮 → 问题 4

问题 4：大反转还是小反转？
  ├→ 大反转 → 趋势可能改变，准备转向
  └→ 小反转 → 只是交易区间中的腿，刮头皮了结
```

### 回答不了的默认假设
| 问题 | 无法判断时的默认 |
|------|-----------------|
| 趋势还是区间？ | 假设是突破，只做顺势 |
| 突破还是通道？ | 假设是突破 |
| 窄通道还是宽通道？ | 假设是窄通道，只在趋势方向交易 |
| 大反转还是小反转？ | 假设是小反转，只刮头皮 |

默认假设的设计逻辑：**保守处理不确定性**——当你无法判断时，选择顺应当前趋势的选项，避免因误判而逆势。

## 与相关概念的关系
- [[fsm-market-cycle]]：四个问题本质上是在定位「突破→窄通道→宽通道→交易区间」的周期位置
- [[market-structure]]：问题 1（趋势还是区间）是二元决策的入口
- [[breakout-mechanics]]：问题 2（突破还是通道）的区分标准
- [[eighty-percent-rule]]：为什么默认假设偏向趋势方向——80% 反转失败
- [[channel-to-trading-range]]：问题 4（大小反转）的判定很大程度上取决于通道→区间的过渡迹象

## 实战应用
在每根 K 线收盘后（或至少每次新波段开始时），用这四个问题重新评估市场状态：
1. 看大局：趋势还是横盘？
2. 看最近走势：像突破（大实体+无缝）还是通道（有回调）？
3. 看回调深度和频率：窄（浅+少）还是宽（深+多）？
4. 看反转强度：大（可能改变方向）还是小（只是区间腿）？

根据答案调整交易策略——同一种入场信号在不同状态下胜率不同。

## 矛盾与待验证
- 默认假设"当不清楚时假设突破/窄通道"是否过于保守？可能导致在宽通道中错失对手方向的机会
- 问题 3 和问题 4 在实际图表上常常同时存在模糊性——当窄/宽和大小反转都看不清时，如何处理？
