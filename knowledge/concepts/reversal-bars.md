# 反转棒

## 一句话定义
反转棒是逆转当前趋势方向的信号棒——分为买入反转棒（做多信号）和卖出反转棒（做空信号），其中多头反转棒/空头反转棒是最强的子类型。

## 核心要点

### 买入反转棒的最低要求
- 收盘在棒线中点之上，**或**
- 收盘高于开盘（多头实体 → 多头反转棒，更强类型）
- 多头反转棒 = 有阳线实体的买入反转棒，是最强买入信号棒

### 卖出反转棒的最低要求
- 收盘在棒线中点之下，**或**
- 收盘低于开盘（空头实体 → 空头反转棒，更强类型）
- 空头反转棒 = 有阴线实体的卖出反转棒，是最强卖出信号棒

### 最好的反转棒特征
- **买入**：开盘接近/低于前棒收盘 + 收盘远高于前棒收盘 + 下影线 1/3-1/2 + 无上影线 + 与前期无重叠 + 好的跟进
- **卖出**：开盘接近/高于前棒收盘 + 收盘远低于前棒收盘 + 上影线 1/3-1/2 + 无下影线 + 与前期无重叠 + 好的跟进

### 反转棒 ≠ 一定是反转实体
- 不是所有买入反转棒都有阳线实体：十字星收在中点之上也是买入反转棒
- 不是所有卖出反转棒都有阴线实体：十字星收在中点之下也是卖出反转棒
- 但阳/阴实体的反转棒胜率更高

### 只有约 1% 的棒是强反转棒
- 如果等待完美，你永远不会交易
- 寻找「看起来还不错」的架构，评估风险/回报和概率是否足够

## 实战应用
当看到一根大实体反向棒、影线短、与前棒少重叠、收盘远超/低于前棒时→这是强反转棒；但必须先确认背景（支撑/阻力、趋势末期等），否则可能是陷阱。
