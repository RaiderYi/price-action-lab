# 二次入场反转

## 一句话定义
反转的第一个入场信号不可靠，第二个（同方向、同区域的）反转信号成功概率远高于第一个。

## 核心要点
- 第一次反转尝试大概率失败（符合 80% 法则）
- 第二次反转尝试 = 第一次失败 + 再次尝试 → 力量积累 → 成功概率显著提升
- Brooks 反复强调：不要追第一次反转，等第二次信号
- 第三次尝试也可以，但成功率提升幅度递减（三推楔形 = 第三次 = 高概率但不是最高）

## 与相关概念的关系
- [[h2-l2-state-machine|H2/L2 State Machine]]：H2/L2 的本质就是二次入场——H1/L1 是第一次推动，H2/L2 是第二次回调入场
- [[three-push-wedge|Three Push Wedge]]：三推楔形的第三次推动就是反转的二次/三次信号
- [[final-flag]]：最终旗形内经常出现两次反转尝试（double bottom/top flag）
- [[reversal-test]]：反转测试本质上就是二次入场——测试成功的回撤提供第二次入场机会
- [[failed-reversal-continuation]]：如果第二次也失败了 → 超强的顺势信号

## 实战应用
1. 看到反转信号 → 标注但不行动
2. 等待价格回到同一区域附近，出现第二个反转信号
3. 第二个信号入场，止损比第一个更紧（因为结构已经更清晰）
4. 如果第二次也失败 → 第三次信号仍然可以尝试，但一旦三次都失败，反转概念基本作废
