# 02 — 入场信号 (Entry Signals)

> 涵盖：Ch41-44（突破入场 + H2/L2 + 回调入场 + 测量移动）
> 核心问题：在什么位置、用什么信号入场？

---

## 一、H2 / L2 信号（最核心的入场形态）

### H2（High 2）— 多头入场
```
定义：在多头趋势中，第二次尝试向上突破回调高点的买点
结构：趋势 → 回调形成低点(L1) → 反弹 → 再次回调形成更高低点(L2) → 突破前高

识别规则：
  ✅ 处于多头趋势中（HL + HH 序列）
  ✅ 两次回调不破趋势线
  ✅ L2 > L1（更高的低点）
  ✅ 突破前一根K线高点时入场
  ⚠️ H3/H4 信号越来越弱（趋势可能即将结束）

入场时机：
  - 激进入场：在L2附近等待止跌信号（十字星、小阳线）
  - 保守入场：等待价格突破前一反弹高点
```

### L2（Low 2）— 空头入场
```
定义：在空头趋势中，第二次尝试向下跌破回调低点的卖点
结构：趋势 → 反弹形成高点(H1) → 下跌 → 再次反弹形成更低高点(H2) → 跌破前低

识别规则：
  ✅ 处于空头趋势中（LH + LL 序列）
  ✅ 两次反弹不破趋势线
  ✅ H2 < H1（更低的高点）
  ✅ 跌破前一根K线低点时入场
```

### H2/L2 失效条件
```
❌ 回调深度超过前一波段的50%
❌ L2 < L1（破了更高的低点）
❌ 入场后3根K线内未向预期方向运动
❌ 出现反向大K线反包
```

## 二、突破入场 (Breakout Entry)

### 强势突破的特征
```
多头突破：
  ✅ 连续2-3根大阳线，收盘在最高位
  ✅ 突破前期摆动高点
  ✅ 突破K线几乎没有上影线
  ✅ 后续K线继续同向运动（确认）
  
空头突破：
  ✅ 连续2-3根大阴线，收盘在最低位
  ✅ 跌破前期摆动低点
  ✅ 几乎没有下影线
```

### 突破入场策略
```
策略1：在突破K线收盘时立即入场（市价）
  - 适合：强突破、大实体K线
  - 止损：突破K线底部下方

策略2：等待回调到突破点再入场
  - 适合：中等强度的突破
  - 等待价格回踩突破点不破

策略3：在突破后的H2/L2入场
  - 适合：错过第一波突破
  - 等回调形成H2/L2结构后入场
```

### 测量缺口 vs 衰竭缺口
```
测量缺口（MG — Measured Gap）：
  突破后持续运动 → 趋势延续 → 持仓

衰竭缺口（EG — Exhaustion Gap）：
  突破后迅速反转 → 趋势可能结束 → 平仓

判断要点：
  - 趋势持续20+根K线后的突破 → 60%概率是衰竭
  - 趋势初期的大突破 → 更可能是测量缺口
  - 高潮（climax）后的突破 → 大概率衰竭
```

## 三、回调入场 (Pullback Entry)

### 回调的定义
```
多头趋势中的回调：
  一根或多根K线的高点低于前一根K线的高点
  （可以同时低点也更低，但关键是高点下降）

空头趋势中的反弹：
  一根或多根K线的低点高于前一根K线的低点
```

### 回调入场时机
```
强势趋势 → 浅回调（< 38%回撤）→ H1 入场即可
中等趋势 → 中等回调（38-50%）→ 等 H2 入场
弱势趋势 → 深回调（> 50%）→ 可能转为交易区间，谨慎
```

### 押注回调失败
```
在强势多头趋势中：
  "多头基于任何理由买入做多"
  - 在阴线收盘做多（押注这是回调，不是反转）
  - 在前低下方1个tick做多（押注假突破）
  - 在50%回撤位做多

核心理念：在明显"始终看涨"的市场中，
  做多的任何理由都比做空好
```

## 四、测量移动 (Measured Move)

### 定义
```
基于前一波段的幅度，推算下一波段的潜在目标位

计算方法：
  多头 MM = 突破点 + (前一上升波段的高度)
  空头 MM = 跌破点 - (前一下跌波段的高度)

例：价格从100涨到110（+10），回调后突破110
    → MM目标 = 110 + 10 = 120
```

### 使用规则
```
✅ 作为TP（止盈）参考，而非入场依据
✅ 接近MM目标时考虑减仓
✅ MM被突破 → 趋势比预期更强 → 继续持有
⚠️ 不要仅因为"到了MM"就反向交易
```

## 五、入场信号评分表

| 维度 | 满分 | 判断标准 |
|------|------|----------|
| 市场环境 | 30 | 趋势>突破>通道>交易区间 |
| 形态结构 | 30 | H2/L2完美 > 一般回调 > 模糊 |
| 入场位置 | 20 | 回调到位 > 追入 > 远离入场区 |
| 量能确认 | 10 | 放量 > 缩量 > 无量 |
| K线确认 | 10 | 强反转K线 > 十字星 > 趋势K线 |

**综合评分**：
- 80+：高置信度，正常仓位
- 60-79：中等置信度，轻仓
- <60：低置信度，观望或微仓

---

## 六、核心原则

```
1. 永远不要追求"完美的交易"——它不存在
2. 在概率和风险回报比之间做出选择
3. 60%的胜率已经是最好的情况了
4. 不要被40%的亏损可能性束缚手脚
5. 一旦"始终看涨/看跌"，立即找机会入场
6. 等待"安全"入场 = 错过趋势的最佳部分
```
