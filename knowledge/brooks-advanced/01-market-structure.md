# 01 — 市场结构 (Market Structure)

> 涵盖：Ch37-40（基础概念+周期）+ Ch48（开盘分析）
> 核心问题：市场现在处于什么状态？应该做多还是做空？

---

## 一、市场三种模式 (The Market Cycle)

市场永远在三种状态间循环，判断当前状态是交易的第一步：

| 模式 | 特征 | 交易策略 |
|------|------|----------|
| **突破 (Breakout)** | 连续同向大K线，收盘在极端位 | 顺势追入，回调加仓 |
| **通道 (Channel)** | 有方向的斜向运动，有回调 | 回调到通道线入场 |
| **交易区间 (Trading Range)** | 横盘，高低点清晰 | 区间上下沿做反转 |

```
市场周期循环：
  突破 → 通道 → 交易区间 → 突破（反向或同向）→ ...
   └─────────────────────────────────────────────┘
```

**关键数据**：
- 约 **10%** 的K线处于突破阶段
- 大多数"2-3根K线突破"是交易区间或宽幅通道的一部分
- 只有 **5%** 的交易日是全天单边强势趋势日
- **90%** 的交易日至少包含两种价格行为类型的切换

## 二、趋势判定 (Trend Identification)

### 多头趋势 (Bull Trend)
```
判定标准：
✅ 连续的 higher high (HH) + higher low (HL)
✅ 阳线实体较大，收盘在高位
✅ 回调（PB）小而浅，不破前低
✅ 均线向上倾斜

做多信号优先级：
  H1 > H2 > H3 > H4（越往后信号越弱）
```

### 空头趋势 (Bear Trend)
```
判定标准：
✅ 连续的 lower low (LL) + lower high (LH)
✅ 阴线实体较大，收盘在低位
✅ 反弹小而弱，不破前高
✅ 均线向下倾斜
```

### 趋势强度判断
- **强趋势**：连续大K线，几乎无回调 → 回调即入场机会
- **弱趋势**：K线实体小，回调深 → 可能转为交易区间
- **趋势末期**：出现高潮（climax）+ 大反转K线 → 警惕反转

## 三、突破判定 (Breakout Identification)

### 多头突破的识别
```
✅ 大阳线实体，收盘接近最高点
✅ 连续2-3根强势阳线
✅ 突破前期阻力位/摆动高点
✅ 突破时成交量放大（如有数据）
✅ 突破后回调不破突破K线底部

⚠️ 假突破特征：
  - 突破K线收盘远离高点（长上影线）
  - 突破后立即被大阴线反包
  - 突破量能不足
```

### 空头突破的识别
```
✅ 大阴线实体，收盘接近最低点
✅ 连续2-3根强势阴线
✅ 跌破前期支撑位/摆动低点
⚠️ 假突破同样关注下影线和反包
```

## 四、开盘分析 (Opening Analysis) — Ch48

### 开盘的三个"部分"（交易者心理框架）
```
开盘阶段（前1-2小时）：
  - 成交量最大，波动最剧烈
  - 市场在"寻找方向"
  - 50%的开盘突破会反转！

中间阶段：
  - 过渡期，可能改变价格行为模式
  - 趋势→区间、区间→趋势的转换常发生于此

尾盘阶段（最后1-2小时）：
  - 成交量再次放大
  - 日内交易者平仓，机构调仓
```

### 开盘反转 (Opening Reversal)
```
核心规则：
  无论开盘突破多么强势，有50%的概率会反转！

识别信号：
  1. 开盘强势上涨/下跌
  2. 触及支撑/阻力后迅速反转
  3. 形成明显的反转K线（pin bar / 吞没）
  4. 反转后朝反方向持续运动

交易策略：
  - 不要在开盘突破的第一根K线追入
  - 等2-3根K线确认方向
  - 如果突破失败反转向下，顺势做反转
```

### 开盘区间 (Opening Range)
```
定义：开盘后第一个波段突破之前的早期交易区间
  - 通常在5-20根K线后才能确定
  - 如果全天横盘，开盘就是最初的交易区间

开盘区间的意义：
  - 区间上沿被突破 → 可能全天走强
  - 区间下沿被跌破 → 可能全天走弱
  - 区间内震荡 → 等待方向选择
```

## 五、市场环境评估框架

每次分析前回答四个问题：

| 问题 | 判断依据 |
|------|----------|
| 1. 现在是趋势还是区间？ | HH/HL vs 横盘 |
| 2. 趋势方向？（多/空） | 大K线方向、均线斜率 |
| 3. 趋势强度？（强/中/弱） | K线实体大小、回调深度 |
| 4. 是否有转换信号？ | 高潮、反转K线、通道突破 |

---

## 六、始终持仓原则 (Always-In)

```
如果你必须在当前K线收盘时选择方向：
  → 选择概率占优的一方（多数大K线的方向）
  → "始终看涨"时任何做多都比做空好
  → 不要因为"涨太多了"而做空
  → 在强势趋势中，即使晚入场也比逆势好
```
