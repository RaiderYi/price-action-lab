> 核心问题：入场后怎么管？什么时候出？亏了怎么办？

## 一、止损设置 (Stop Loss)

### 三种止损保护
```
每笔交易必须同时使用三种保护：

1. 硬止损（Hard Stop）
   → 始终在市场中挂有止损单
   → 不设心理止损！必须实际挂单

2. 信号止损（Signal Stop）
   → 出现合理反向信号时立即退出
   → 不需要完美的反向信号，合理即可

3. 突破止损（Breakout Stop）
   → 出现强势反向突破时立即退出
   → 连续多根反向强势K线 = 必须出
```

### 止损位置选择
```
多头止损设置选项（选其一）：
  ✅ 突破K线底部下方
  ✅ 最近走势段（leg）底部下方
  ✅ 主要更高低点（HL）下方
  ✅ 资金止损（固定金额/点数）

空头止损设置选项（选其一）：
  ✅ 突破K线顶部上方
  ✅ 最近走势段顶部上方
  ✅ 主要更低高点（LH）上方
```

### 止损宽度权衡
```
窄止损：
  + 每笔亏损小
  - 被扫损频率高
  - 胜率较低

宽止损：
  + 胜率更高
  - 每笔亏损大
  
选择：符合你个性的方式
  偏好高胜率 → 宽止损
  偏好小亏损 → 窄止损
  100笔交易后结果一样——关键是坚持一致
```

### 移动止损（Trailing Stop）
```
每次新的强势突破创出新高/新低后：
  → 将止损移至新走势段的底部/顶部下方/上方
  → 只要保持在最后一个主要HL/LH之上/之下 → 趋势完整
  → 如果被突破 → 趋势可能结束，持有不再有意义
```

## 二、止盈与退出 (Take Profit & Exit)

### 测量移动目标（MM）
```
TP1 = 第一测量移动目标 → 减仓1/3-1/2
TP2 = 第二测量移动目标 → 继续减仓
TP3 = 趋势延续 → 移动止损跟踪

不要仅因"到了MM目标"而全部平仓
如果趋势强劲，MM会被突破
```

### 反向信号退出
```
出现以下任一情况立即评估退出：
  1. 合理的反向信号K线（不需要完美）
  2. 3根以上连续反向强势K线
  3. 趋势转为交易区间
  4. 主要HL/LH被突破

高手原则：
  如果明显错误，在止损被触发前就退出
  不要等止损——等止损是最贵的退出方式
```

### 交易时段结束
```
临近收盘时：
  → 更快退出
  → 反转可能今天不会回来救你
  → 尾盘由"买入收盘"驱动的趋势 → 反转时快速出
```

### 被止损后重新入场
```
如果被止损出局但趋势恢复：
  ✅ 可以重新入场
  ✅ 不要因为"已经亏了一次"就放弃
  ✅ 把重新入场当作独立的新交易
  
如果反转失败、趋势恢复：
  随时恢复仓位——没有重新入场的心理障碍
```

## 三、仓位与风险管理

### 仓位大小
```
基本原则：
  如果止损距离较远 → 减小仓位规模
  使每笔交易的风险金额保持一致

仓位 = 可接受亏损金额 / (入场价 - 止损价)
```

### 加仓策略（Scaling In）
```
在强势趋势中：
  高手会在每次连续阳线/阴线收盘时加仓
  逐步增加盈利交易的投入

加仓条件：
  ✅ 趋势明确且强劲
  ✅ 前一个仓位已盈利
  ✅ 总风险可控
  
注意：
  加仓 = 增加风险暴露
  大多数交易者买入一次然后波段交易即可
```

### 部分止盈 + 部分波段
```
在强趋势中：
  至少对部分仓位进行波段交易
  另一部分刮头皮了结
  
示例：
  入场后 → 50%在TP1刮头皮了结
        → 50%用移动止损做波段
```

## 四、交易心理与纪律

### 亏损分析
```
即使是高手：
  大多数亏损交易是由于错误，而非运气不好！

高手亏损少的原因：
  ✅ 迅速平仓（不拖延）
  ✅ 不对某个观点产生情绪依附
  ✅ 承认错误比等待反转更便宜
```

### 防止大额亏损的规则
```
1. 始终在市场中挂有止损单（最重要！）
2. 出现合理反向信号时退出
3. 出现强势反向突破时退出
4. 趋势转为交易区间 → 退出评估
5. 接近交易时段结束 → 更快退出
```

### 初学者常见错误
```
❌ 使用心理止损（不实际挂单）
❌ 盈利时过早获利了结（"害怕利润回吐"）
❌ 亏损时不肯止损（"它会回来的"）
❌ 追求"完美交易"（不存在的东西）
❌ 因为错过第一波而放弃整个趋势
❌ 用"涨太多了"作为做空的理由

✅ 正确心态：
  - 60%胜率已经是最好情况
  - 接受40%的亏损交易
  - 让盈利奔跑，截断亏损
  - 任何合理理由入场都比错过好
```

## 五、交易者等式 (Trader's Equation)

```
盈利 = (胜率 × 平均盈利) - (败率 × 平均亏损)

要获得正期望值：
  方法1：高胜率 + 小额亏损（刮头皮风格）
  方法2：中等胜率 + 让盈利奔跑（波段风格）
  方法3：低胜率 + 巨大盈亏比（趋势跟踪风格）

关键：
  选择适合你个性的方法并坚持
  三种方法都能赚钱
  来回切换 = 必亏
```

## 六、快速决策清单

入场后每根K线问自己：

| 检查项 | 行动 |
|--------|------|
| 趋势还在吗？ | 在 → 持有 / 不在 → 准备出 |
| 出现反向信号了吗？ | 是 → 退出 / 否 → 继续 |
| 到测量移动目标了吗？ | 是 → 减仓 / 否 → 持有 |
| 是交易区间了吗？ | 是 → 上下沿操作 / 否 → 趋势策略 |
| 快到收盘了吗？ | 是 → 收紧止损 / 否 → 正常 |
