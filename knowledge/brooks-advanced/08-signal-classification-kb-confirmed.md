# KB 确认后信号分类补充
# 基于 Al Brooks 知识库确认结果

## eighty_twenty — 不是信号，是统计原则

**KB 确认结论**：Eighty-Twenty 是 Brooks 总结的统计规律——在交易区间内，80% 的突破尝试会失败。**它不是独立信号，而是 TR Fade 策略背后的核心概率支持。**

**系统处理**：
- 从 TRADE_READY 信号中移除
- 重新分类为 context_factor / principle
- 不独立产生交易候选
- 作为 tr_fade 的置信度增强因子

---

## measured_move — 目标位测算工具，非入场信号

**KB 确认结论**：基于市场对称性原则，预测后续价格波段目标的计算方法。**不用于决定何时入场。**

**系统处理**：
- 保持 STRUCTURE_READY（当前已正确）
- 不作为独立入场信号输出
- 仅用于 TP 目标位参考
- 在报告中标注为"目标投影工具"

---

## double_bottom / double_top — H2/L2 的形态化表达

**KB 确认结论**：
- 每个小型双底都是 H2 买入设置
- 每个小型双顶都是 L2 卖出设置
- 双底/顶是 H2/L2 的具体形态表现，不是独立信号类型

**系统处理**：
- 保持 classic_ta 分类
- 不降级（因为其本质是 H2/L2 的形态确认）
- KB 定义补充后保持 TRADE_READY
- 在报告中说明其与 H2/L2 的关系

---

## buy_the_close / sell_the_close — 非核心 Brooks 信号

**KB 确认结论**：这是一种特定的入场时机策略，而非基于明确 K 线形态或结构的信号。**非核心，优先级低于所有形态与结构信号。**

**系统处理**：
- 保持 disabled（当前已正确）
- 不作为独立信号恢复生产
- 可选作为 context feature 保留

---

## tr_fade — 交易区间核心策略

**KB 确认结论**：在交易区间底部 1/3 买入，顶部 1/3 卖出。是区间内主导的"低买高卖"策略。需要：清晰区间边界 + 边界拒绝K线。

**系统处理**：
- 保持 TRADE_READY
- KB 定义已由本次确认补全
- 后续需增加 range_width / boundary_touches 等字段的检测
