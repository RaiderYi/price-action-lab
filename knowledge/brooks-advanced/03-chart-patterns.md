# 03 — 图表形态 (Chart Patterns)

> 涵盖：Ch45-48（通道、楔形、高潮、三角形、交易区间、开盘形态）
> 核心问题：当前K线正在形成什么形态？预示着什么方向？

---

## 一、通道 (Channel)

### 紧密通道 vs 宽幅通道

| 特征 | 紧密通道 | 宽幅通道 |
|------|----------|----------|
| K线重叠 | 少，K线依次排列 | 多，K线大量重叠 |
| 回调深度 | < 30% 回撤 | 30-100% 回撤 |
| 交易策略 | 只做趋势方向 | 可双向刮头皮 |
| 更高时间周期 | 仍是通道 | 看起来是紧密通道 |
| 本质上 | 强趋势 | **向上倾斜的交易区间** |

### 宽幅通道的识别
```
✅ 走势段平均大小 ≥ 最小刮头皮利润的3倍
✅ 走势段大小 ≥ 平均K线大小的2-3倍
✅ 回调经常超过50%，有时达100%
✅ 通常包含嵌套的交易区间
✅ 在更高时间周期（如日线）上看起来是紧密通道

交易策略：
  - 5分钟图宽幅通道 → 主要做刮头皮，可双向
  - 日线图宽幅通道 → 波段做多，忽略短期波动
```

### 通道交易规则
```
紧密多头通道：只买入做多，回调即机会
宽幅多头通道：上半部分做空(刮头皮)，下半部分做多(波段+刮头皮)
空头通道： 只卖出做空，反弹即机会
```

## 二、楔形 (Wedge)

### 楔形顶部（Wedge Top）
```
定义：上升通道中斜率逐渐变缓，形成楔形 → 大概率反转下跌

识别（需要三次推动）：
  第1波：强势上涨，陡峭
  第2波：上涨但力度减弱，角度变缓
  第3波：上涨更弱，角度更缓 → 楔形完成

在5分钟图上：
  当宽幅多头通道出现楔形顶部时
  → 大概率反转或转为交易区间
  → 剩余时间不足以再进行多头波段交易
```

### 楔形底部（Wedge Bottom）
```
定义：下降通道中斜率逐渐变缓 → 大概率反转上涨
结构与顶部对称（三次下跌推动，力度递减）

H3/L3 信号：
  楔形本质上 = H3或L3（第三次推动）
  H3 = 第三次回调做多（比H2弱）
  L3 = 第三次反弹做空（比L2弱）
  越往后信号越弱，但楔形突破后反转概率高
```

## 三、高潮与反转 (Climax & Reversal)

### 买入高潮 (Buying Climax)
```
特征：
  ✅ 大阳线实体，连续2-3根以上
  ✅ 突然的加速上涨
  ✅ 与前期的温和走势形成鲜明对比
  ✅ 成交量可能放大

判断规则：
  趋势持续20+根K线后出现的大突破 → 60%概率是衰竭
  趋势初期的大突破 → 更可能是测量缺口（继续）

交易策略：
  初学者：平掉多头仓位，不再买入
  高手：可在高潮K线收盘时试探做空
  注意：高潮后经常出现第二次高潮才真正反转
```

### 卖出高潮 (Selling Climax)
```
特征和规则与买入高潮对称

初学者：平掉空头仓位，不再卖出
高手：可在高潮K线收盘时试探做多
```

### 高潮后的典型走势
```
高潮 → 第一次小反转（很多交易者不信任）
     → 回测高潮区域（不给新低/新高）→ 二次确认
     → 真正的趋势反转
     
不要在第一根反转K线就全仓反向
等二次确认（higher low 或 lower high）
```

## 四、交易区间 (Trading Range)

### 识别交易区间的早期迹象
```
以下迹象越多 → 越可能是交易区间而非趋势：

1. 高概率形态频繁失效
2. 低概率形态却经常成功
3. 强势突破后迅速被反转
4. 大幅上涨后立即大幅下跌（困惑市场）
5. K线大量重叠，影线多
6. 存在至少两波上涨 + 两波下跌走势段
   （每波持续10-20根K线以上）

核心理念：
  "80%的突破在交易区间内会失败"
  当市场横盘时，在顶部做空、底部做多
  逐步加仓而非一次性全仓
```

### 交易区间交易规则
```
宽幅交易区间：波段 + 刮头皮
紧密交易区间：最好不交易，或用限价单+刮头皮

入场：
  区间上三分之一 → 只做空
  区间下三分之一 → 只做多
  区间中段 → 观望或刮头皮

止损：设在区间外1-2个tick
止盈：区间对侧（或刮头皮利润即走）
```

### 嵌套结构（分形）
```
市场是分形的：形态包含更小的相似形态
  日线交易区间 → 30分钟包含更小的交易区间
  30分钟交易区间 → 5分钟包含更小的交易区间
  
这解释了为什么不同时间周期的信号方向可能不同
→ 大周期定方向，小周期找入场
```

## 五、开盘形态速查

| 形态 | 特征 | 概率 |
|------|------|------|
| 开盘突破 | 开盘即强势单向运动 | 50%会反转 |
| 开盘区间 | 前30-60分钟横盘 | 等待突破方向 |
| 开盘反转 | 先突破后反转 | 反转后跟随 |
| 强势趋势日 | 全天单边 | 仅10%的交易日 |

## 六、形态决策树

```
看到强势突破 →
  趋势初期？ → 测量缺口(MG) → 顺势入场
  趋势20+根K线后？ → 60%衰竭缺口(EG) → 平仓
  
看到回调 →
  浅回调(<38%)？ → H1入场/加仓
  中等回调(38-50%)？ → 等H2入场
  深回调(>50%)？ → 可能转交易区间
  
看到连续三次推动 →
  楔形 → 即将反转 → 准备反向
  
看到困惑市场（大涨+大跌交替）→
  交易区间 → 上下沿操作
```
